## 광선-오브젝트 교차

### 구 교차

이차방정식으로 레이-구 교차를 판정한다.

```
Ray: P(t) = O + t * D
Sphere: |P - C|^2 = r^2

대입:
|O + tD - C|^2 = r^2
(D*D)t^2 + 2(D*(O-C))t + ((O-C)*(O-C) - r^2) = 0

a = D*D = 1 (방향 정규화)
oc = O - C
b = 2 * (D . oc)
c = oc.oc - r^2

판별식 disc = b^2 - 4ac
disc < 0  -> 교차 없음
disc >= 0 -> t = (-b +/- sqrt(disc)) / 2a, 가장 작은 양의 t 선택
```

- `radius_sq` (반지름 제곱)을 `t_sphere_data`에 사전 캐싱하여 제곱 연산 절감
- 법선: `normalize(hit_point - center)`

### 평면 교차

내적으로 레이-평면 교차를 판정한다.

```
Plane: (P - P0) . N = 0  (P0: 평면 위 점, N: 법선)
Ray: P(t) = O + tD

대입:
(O + tD - P0) . N = 0
t = ((P0 - O) . N) / (D . N)

D . N ~ 0 -> 평행 (교차 없음)
t >= RAY_T_MIN -> 유효한 교차
```

- 양면 렌더링: `dot(ray.direction, normal) > 0`이면 법선을 반전하여 레이 반대 방향을 보장한다.

### 원기둥 교차

원기둥은 측면(무한 실린더)과 양쪽 캡(원형 디스크)을 개별 판정한 뒤 가장 가까운 교차를 선택한다.

**측면 교차**: 축 방향을 제거하여 2D 원 교차 문제로 환원한다.

```
축: A (정규화)
oc = O - C (중심까지 벡터)

D_perp  = D  - (D.A)A     // 방향의 축 직교 성분
oc_perp = oc - (oc.A)A    // oc의 축 직교 성분

a = D_perp . D_perp
b = 2 * (D_perp . oc_perp)
c = oc_perp . oc_perp - r^2

판별식으로 t 계산 후, 높이 검증:
m = (D.A) * t + (oc.A)
|m| <= half_height -> 유효
```

**캡 교차**: 양쪽 캡(상단/하단)을 각각 판정한다.

```
상단 캡: cap_center = center + half_height * axis
하단 캡: cap_center = center - half_height * axis

t = ((cap_center - O) . axis) / (D . axis)
hit_point = O + t * D
|hit_point - cap_center|^2 <= r^2 -> 유효
```

**법선 계산**:
- 측면: `normalize(hit_point - (center + m * axis))`, `dot(ray.dir, normal) > 0`이면 반전
- 캡: 초기값 `axis`, `dot(ray.direction, normal) > 0`이면 반전

### 원뿔 교차

원뿔은 측면(테이퍼된 곡면)과 밑면 캡(원형 디스크)을 개별 판정한다. 꼭짓점은 점이므로 apex 캡은 없다.

**측면 교차**: apex 기준 이차방정식으로 교차를 판정한다.

```
apex = center + axis * half_height
d = O - apex (레이 원점에서 apex까지)
k = radius / (2 * half_height)  (기울기)
k2 = 1 + k^2

a = D.D - k2 * (D.A)^2
b = 2(D.d - k2 * (D.A)(d.A))
c = d.d - k2 * (d.A)^2

높이 검증: m in [-2*half_height, 0]
```

**법선 계산**:
- 측면: `normalize((P - apex) - m * (1 + k^2) * axis)`
- 밑면 캡: 초기값 `-axis`, `dot(ray.direction, normal) > 0`이면 반전

### 교차 분기(dispatch)

`intersect_object(ray, obj, hit)`가 오브젝트 타입에 따라 적절한 교차 함수를 호출한다:

```c
if (obj->type == OBJ_SPHERE)    -> 구 교차
if (obj->type == OBJ_PLANE)     -> 평면 교차
if (obj->type == OBJ_CYLINDER)  -> 원기둥 교차
if (obj->type == OBJ_CONE)      -> 원뿔 교차
```

모든 교차 함수는 가장 가까운 양의 `t` 값(RAY_T_MIN 이상)을 찾아 `t_hit` 구조체에 기록한다. 교차 성공 시 `hit->obj`에 오브젝트 포인터가 설정된다.

## BVH 가속 구조

BVH(Bounding Volume Hierarchy)는 공간 분할 기법으로 광선-오브젝트 교차 검사를 O(n)에서 O(log n)으로 최적화한다. v2.1.0부터 기본 활성화되어 있다.

```
            [루트 AABB]
           /           \
    [왼쪽 AABB]    [오른쪽 AABB]
      /    \          /      \
  [obj1] [obj2]   [obj3]   [obj4]
```

### Plane 분리 전략

Plane의 AABB는 `[-1e6, 1e6]^3`으로 극도로 넓어 BVH 트리의 모든 분할을 무력화한다. 이를 해결하기 위해 v2.2.0부터 Plane을 BVH 트리에서 제외한다.

- `build_scene_bvh()`에서 Plane 인덱스를 `t_plane_refs`에 별도 저장
- Bounded 오브젝트(sphere, cylinder, cone)만 BVH 트리에 포함
- BVH 순회 후 Plane을 선형 테스트

### 구축 알고리즘

Spatial midpoint split 방식으로 재귀적으로 구축한다.

```
bvh_build_recursive(objects, count, scene, depth)
 ├── count <= 2 || depth > 20 -> create_leaf_node()
 ├── compute_bounds()         // 전체 오브젝트 AABB 합산
 ├── choose_split_axis()      // 가장 긴 축 선택
 ├── calculate_split_position() // AABB 중심점 기준 분할점
 ├── partition_objects()      // 분할점 기준 좌/우 분리
 └── create_split_node()
      ├── bvh_build_recursive(left, ...)
      └── bvh_build_recursive(right, ...)
```

- **Split axis**: AABB의 가장 긴 축 (x/y/z)
- **Split position**: AABB 중심점 `(bounds.min + bounds.max) / 2.0`
- **Leaf threshold**: 오브젝트 수 <= 2 또는 깊이 > 20이면 리프 노드 생성

오브젝트별 AABB 계산:

| 오브젝트 | AABB |
|---------|------|
| Sphere | center +/- radius |
| Cylinder | center +/- (radius + |half_axis|) 각 축별 |
| Cone | center +/- (radius + |half_axis|) 각 축별 |
| Plane | 제외 (별도 관리) |

### AABB 교차

Slab method로 광선-AABB 교차를 판정한다.

1. 각 축(x, y, z)별로 `t0`, `t1`을 계산한다 (`safe_slab_axis`).
2. `inv_dir` (사전 계산)로 나눗셈을 곱셈으로 대체한다.
3. 모든 축의 `[t0, t1]`을 `tmin`, `tmax`에 누적하여 교집합이 비어있지 않으면 교차이다.

```c
int aabb_intersect(t_aabb box, t_ray ray, double *t_min, double *t_max)
```

### Primary ray 순회

```
bvh_node_intersect(node, ray, hit, scene)
 ├── aabb_intersect() -> miss -> return 0
 ├── leaf -> intersect_object() per object
 └── internal node
      ├── ordered traversal (ray 방향 기준 가까운 자식 먼저)
      ├── first child intersect
      ├── t_max pruning: second child AABB.tmin > current hit.distance -> skip
      └── second child intersect
```

- **Ordered traversal**: `ray.direction[split_axis]`가 양수면 left 먼저, 음수면 right 먼저
- **t_max pruning**: 이미 찾은 hit보다 먼 노드는 탐색하지 않음

### Shadow ray any-hit

```
bvh_any_hit(bvh, ray, max_dist, scene)
 ├── BVH 순회 (bounded 오브젝트만)
 └── 첫 번째 hit 발견 시 즉시 return 1 (early exit)
```

- Any-hit 모드: 그림자 판정은 "차폐 여부"만 필요하므로 가장 가까운 교차가 아닌 아무 교차에서 즉시 종료
- **SHADOW_BVH_THRESHOLD = 5**: 오브젝트 5개 초과이면 BVH를 사용하고, 이하이면 brute-force

### Plane 분리 효과

S4 씬 (7sp + 7cy + 3pl) 기준 벤치마크:

| 지표 | plane 포함 BVH | plane 분리 BVH |
|------|---------------|---------------|
| BVH skip rate | 32.9% | **82.0%** |
| Shadow tests | 369.6M | **83.7M** |
| Frame time | 25.6s | **6.1s** |

Plane의 `[-1e6, 1e6]^3` AABB가 BVH 트리의 모든 분할을 무력화했기 때문에, 분리만으로 극적인 개선이 발생한다.

## BVH 시각화

`--bvh-vis` 플래그로 BVH 트리 구조를 콘솔에 출력한다. `src/spatial/debug/`의 `bvhd_*` 파일들이 담당한다.

```bash
./miniRT --bvh-vis scenes/valid/valid_scene_comprehensive.rt
```

출력 예시:

```
BVH Tree (depth=0, axis=X)
├── [L] depth=1, axis=Y, bounds=[...]
│   ├── [L] LEAF: sp-1, sp-2
│   └── [R] LEAF: sp-3
└── [R] depth=1, axis=Z
    └── LEAF: cy-1, cy-2
```

트리 깊이, 분할 축, AABB 범위, 리프 노드의 오브젝트 목록 등을 확인할 수 있다.
