# 인터랙티브 컨트롤

miniRT는 실시간 인터랙티브 컨트롤을 통해 장면을 동적으로 조작할 수 있습니다.

---

## 카메라

### 이동

| 키 | 동작 | 방향 |
|----|------|------|
| **W** | 전진 | 카메라가 보는 방향 |
| **X** | 후진 | 카메라 뒤쪽 |
| **A** | 좌측 이동 | 카메라 왼쪽 (시야 직교 방향) |
| **D** | 우측 이동 | 카메라 오른쪽 (시야 직교 방향) |
| **Q** | 상승 | 월드 Y축 위쪽 |
| **Z** | 하강 | 월드 Y축 아래쪽 |

이동 거리: 키당 1.0 단위

### 회전

| 키 | 동작 |
|----|------|
| **E** | 상하 회전 — 위 (pitch up) |
| **C** | 상하 회전 — 아래 (pitch down) |
| **1** | 좌우 회전 — 좌 (yaw left) |
| **3** | 좌우 회전 — 우 (yaw right) |

회전 각도: 키당 5도

### 리셋

| 키 | 동작 |
|----|------|
| **S** | 초기 위치/방향 복원 (pitch/yaw 재계산) |

## HUD

HUD(Head-Up Display)는 화면 위에 씬 정보와 성능 메트릭을 오버레이로 표시합니다. H 키로 토글할 수 있습니다.

### 표시 정보

**씬 정보**:
- 카메라 위치, 방향, FOV
- Ambient 비율 및 색상
- 조명 위치, 밝기, 색상

**오브젝트 목록**:
- 오브젝트 ID, 타입, 위치
- 선택된 오브젝트 강조 표시
- 페이지네이션 지원 (페이지당 `HUD_OBJECTS_PER_PAGE = 8`개)
- Up / Down 키로 페이지 이동

**성능 메트릭**:
- FPS (Frames Per Second)
- 프레임 렌더 시간 (밀리초)
- BVH 상태 (ON/OFF)

### 페이지네이션

오브젝트 수가 8개를 초과하면 페이지 단위로 분할됩니다:

```
전체 오브젝트: 40개
페이지당: 8개
전체 페이지: 5
현재 페이지: 1/5

Up / Down 키로 페이지 이동
```

## 키가이드

키가이드는 화면에 현재 사용 가능한 키 바인딩을 오버레이로 표시하는 기능입니다.

- H 키로 HUD와 함께 토글
- 카메라, 오브젝트, 광원 조작 키 목록을 정적 텍스트로 표시

## 디바운스 렌더링

miniRT는 디바운스 렌더링 시스템을 사용하여 부드러운 인터랙션과 렌더링 효율을 양립합니다. 렌더링 시스템은 4가지 상태로 동작하는 유한 상태 머신(FSM)으로 구현되어 있습니다.

### 상태 전이 다이어그램

```
IDLE --> ACTIVE --> FINAL --> COOLDOWN
  ^                              |
  +------------------------------+
```

### 상태 설명

**1. IDLE (대기)**:
- 사용자 입력 없음
- 렌더링 수행 안 함

**2. ACTIVE (활성)**:
- 사용자 입력 감지 시 진입
- 50ms 간격으로 저품질(LQ) 프리뷰 트리거
- 150ms 동안 추가 입력이 없으면 FINAL로 전환

**3. FINAL (최종)**:
- 고품질 최종 렌더링 수행
- 완료 후 COOLDOWN으로 전환

**4. COOLDOWN (냉각)**:
- 350ms 동안 추가 렌더링 억제
- 완료 후 IDLE로 복귀

### 품질 모드 비교

| 항목 | Full Quality (고품질) | Low Quality (저품질) |
|------|----------------------|---------------------|
| 픽셀 렌더링 | 1x1 (전체 픽셀) | 2x2 블록 렌더링 |
| 그림자 샘플 | 전체 샘플 | 감소된 샘플 |
| 트리거 조건 | 입력 정지 후 150ms 경과 | 입력 중 50ms 간격 |
| 용도 | 최종 결과물 | 인터랙션 중 즉각적 피드백 |

### 동작 흐름 요약

```
사용자 입력 --> 50ms 간격 LQ 프리뷰 --> 150ms 입력 없음 --> 최종 렌더 (고품질) --> 350ms 냉각
```
