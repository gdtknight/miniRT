# 인터랙티브 컨트롤

miniRT는 실시간 인터랙티브 컨트롤을 통해 장면을 동적으로 조작할 수 있습니다.

---

## 🎮 카메라 컨트롤

### 이동 (Translation)

| 키 | 동작 | 방향 |
|----|------|------|
| **W** | 전진 | 카메라가 보는 방향 |
| **X** | 후진 | 카메라 뒤쪽 |
| **A** | 좌측 이동 | 카메라 왼쪽 |
| **D** | 우측 이동 | 카메라 오른쪽 |
| **Q** | 상승 | 월드 Y축 위쪽 |
| **Z** | 하강 | 월드 Y축 아래쪽 |

**이동 거리**: 키당 1.0 단위

### 회전 (Rotation)

| 키 | 동작 |
|----|------|
| **E** | 피치 위 (고개 올림) |
| **C** | 피치 아래 (고개 내림) |
| **1** | 요 좌 (좌회전) |
| **3** | 요 우 (우회전) |

**회전 각도**: 키당 5도

### 리셋

| 키 | 동작 |
|----|------|
| **S** | 초기 위치/방향 복원 |

| **V** | Z | - |

## 📊 HUD 정보

HUD가 표시되면 다음 정보를 볼 수 있습니다:

### 장면 정보
- 총 객체 수 (구체/평면/원기둥/원뿔)
- 카메라 위치 및 방향
- 광원 위치 및 밝기

### 선택된 객체
- 객체 타입
- 위치
- 크기 (지름/높이)
- 색상 (RGB)

### 성능 메트릭
- FPS (Frames Per Second)
- 렌더링 시간 (밀리초)
- BVH 통계 (노드 수, 깊이)

## 🔄 렌더링 동작

### 디바운싱 (Debouncing)

miniRT v2.3.0은 디바운싱 렌더링 시스템을 사용하여 부드러운 인터랙션을 제공합니다.

**작동 원리**:
- 입력 시 50ms 간격으로 LQ preview 트리거
- 150ms 입력 없으면 full quality 렌더링
- 이후 350ms cooldown

**사용자 경험 개선**:
- 입력 버퍼링 제거로 부드러운 조작감
- 불필요한 렌더링 90% 이상 감소
- 입력 지연 없는 즉각적인 반응

### 4-상태 렌더링 기계

렌더링 시스템은 4가지 상태로 동작합니다:

```
IDLE → ACTIVE → FINAL → COOLDOWN
  ↑                          ↓
  └──────────────────────────┘
```

**1. IDLE (대기)**:
- 사용자 입력 없음
- 렌더링 없음

**2. ACTIVE (활성)**:
- 사용자 입력 감지
- 50ms 간격으로 LQ preview 트리거
- 150ms 입력 없으면 FINAL로 전환

**3. FINAL (최종)**:
- 고품질 최종 렌더링
- 완료 후 COOLDOWN 상태로 전환

**4. COOLDOWN (대기)**:
- 350ms 동안 추가 렌더링 억제
- 완료 후 IDLE 상태로 복귀

### LQ 프리뷰 모드 (Low Quality Preview)

**개요**: 인터랙션 중 즉각적인 시각적 피드백을 제공하는 저품질 렌더링 모드입니다 (2x2 블록).

**특징**:
- **즉각적 반응**: 50ms 간격으로 LQ preview 트리거
- **자동 전환**: 입력 정지 후 고품질 최종 렌더로 자동 업그레이드
- **품질 조정**: 2x2 블록 렌더링, 그림자 샘플 감소 등으로 속도 향상

**사용자 이점**:
- 카메라나 객체를 움직일 때 즉시 결과 확인
- 입력 지연 없는 부드러운 인터랙션
- 최종 품질과 반응 속도의 균형

**작동 방식**:
```
사용자 입력 → 50ms 간격 LQ preview → 150ms 입력 없음 → 최종 렌더 (고품질) → 350ms cooldown
```
