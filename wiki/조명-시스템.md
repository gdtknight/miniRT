# 조명 시스템

miniRT의 조명 시스템은 Phong 반사 모델을 기반으로 하며, Soft Shadow를 지원합니다.

---

## 💡 Phong 조명 모델

Phong 모델은 3가지 요소로 구성됩니다:

```
최종 색상 = Ambient + Diffuse + Specular
```

### 1. Ambient (주변광)

환경의 간접 조명을 시뮬레이션합니다. 모든 점에서 동일합니다.

**공식**:
```
I_ambient = K_a × I_a × object_color
```

**변수**:
- `K_a`: 물체의 주변광 반사 계수 (보통 1.0)
- `I_a`: 주변광 강도 (씬 파일에서 정의)
- `object_color`: 물체의 색상

**구현**:
```c
vec3 calculate_ambient(scene, object)
{
    vec3 ambient_color = scene.ambient.color;
    float ambient_ratio = scene.ambient.ratio;  // 0.0 ~ 1.0
    
    vec3 result = multiply_color(ambient_color, object.color);
    result = scale_color(result, ambient_ratio);
    
    return result;
}
```

### 2. Diffuse (난반사)

Lambert의 코사인 법칙을 따릅니다. 표면이 광원을 직접 향할수록 밝아집니다.

**공식**:
```
I_diffuse = K_d × I_d × (N · L) × object_color
```

**변수**:
- `K_d`: 난반사 계수 (보통 1.0)
- `I_d`: 광원의 밝기
- `N`: 표면 법선 (정규화)
- `L`: 교차점에서 광원으로의 방향 (정규화)
- `N · L`: 두 벡터의 내적 (cos θ)

**구현**:
```c
vec3 calculate_diffuse(hit_point, normal, light, object)
{
    // 교차점에서 광원으로의 방향
    vec3 light_dir = normalize(sub(light.position, hit_point));
    
    // 법선과 광원 방향의 내적
    float diff = dot(normal, light_dir);
    
    // 음수는 0으로 (뒷면 제거)
    if (diff < 0)
        diff = 0;
    
    // 조명 색상과 객체 색상 혼합
    vec3 light_color = scale_color(light.color, light.brightness);
    vec3 result = multiply_color(light_color, object.color);
    result = scale_color(result, diff);
    
    return result;
}
```

### 3. Specular (정반사)

광택 있는 표면의 하이라이트를 시뮬레이션합니다.

**공식**:
```
I_specular = K_s × I_s × (R · V)^n × light_color
```

**변수**:
- `K_s`: 정반사 계수 (보통 0.5)
- `I_s`: 광원의 밝기
- `R`: 반사 벡터
- `V`: 시선 벡터 (교차점에서 카메라로)
- `n`: Shininess (광택도, 보통 32)

**반사 벡터 계산**:
```
R = 2(N · L)N - L
```

**구현**:
```c
vec3 calculate_specular(hit_point, normal, light, camera)
{
    vec3 light_dir = normalize(sub(light.position, hit_point));
    vec3 view_dir = normalize(sub(camera.position, hit_point));
    
    // 반사 벡터: R = 2(N·L)N - L
    float nl_dot = dot(normal, light_dir);
    vec3 reflect_dir = sub(
        scale(normal, 2.0 * nl_dot),
        light_dir
    );
    
    // (R · V)^n
    float spec = dot(reflect_dir, view_dir);
    if (spec < 0)
        spec = 0;
    
    float shininess = 32.0;
    spec = pow(spec, shininess);
    // 실제 구현에서는 pow() 대신 fast_pow32()를 사용합니다.
    // fast_pow32()는 5번의 곱셈만으로 x^32를 계산하여 성능을 향상시킵니다.

    // Specular는 광원 색상만 사용 (물체 색상 없음)
    vec3 result = scale_color(light.color, light.brightness * 0.5 * spec);
    
    return result;
}
```

### 최종 조명 계산

현재 구현은 복수 광원을 지원합니다. 각 광원에 대해 그림자, 난반사, 정반사를 개별 계산하고 기여도를 누적합니다.

```c
vec3 calculate_lighting(hit_point, normal, object, scene)
{
    vec3 color = vec3(0, 0, 0);

    // 0. 텍스처 적용 (checker/bump)
    // checkerboard가 활성화된 경우 객체 색상을 교체
    // bump map이 활성화된 경우 법선을 섭동(perturb)

    // 1. Ambient
    color = add_color(color, calculate_ambient(scene, object));

    // 2. 각 광원에 대해 조명 기여도 계산
    // for each light in scene.lights[0..light_count-1]:
    for (int i = 0; i < scene.light_count; i++)
    {
        light = scene.lights[i];

        // 그림자 체크
        float shadow_factor = calculate_shadow(hit_point, normal, light);

        if (shadow_factor > 0)
        {
            // Diffuse
            vec3 diffuse = calculate_diffuse(hit_point, normal,
                                             light, object);
            color = add_color(color, scale_color(diffuse, shadow_factor));

            // Specular
            vec3 specular = calculate_specular(hit_point, normal,
                                               light, scene.camera);
            color = add_color(color, scale_color(specular, shadow_factor));
        }
    }

    // 색상 클램핑 [0, 255]
    color = clamp_color(color);

    return color;
}
```

## 🌑 그림자 시스템

### Shadow Ray

교차점이 광원으로부터 빛을 받는지 확인합니다:

```c
bool is_in_shadow(hit_point, light_position, scene)
{
    // 교차점에서 광원으로의 광선
    vec3 to_light = sub(light_position, hit_point);
    float light_distance = length(to_light);
    vec3 light_dir = normalize(to_light);
    
    // Shadow bias (Shadow Acne 방지)
    vec3 shadow_origin = add(hit_point, scale(light_dir, 0.001));
    
    ray shadow_ray = { origin: shadow_origin, direction: light_dir };
    
    // 광원까지의 경로에 장애물이 있는지 확인
    for (object in scene.objects)
    {
        float t;
        if (intersect(shadow_ray, object, &t))
        {
            // 장애물이 광원보다 가까우면 그림자
            if (t < light_distance)
                return true;
        }
    }
    
    return false;
}
```

### Soft Shadows

실제 세계의 광원은 점이 아니라 면적을 가지므로, 부드러운 그림자 경계(penumbra)가 생깁니다.

**원리**: 광원 주변의 여러 지점에서 샘플링하여 평균을 냅니다.

```c
float calculate_soft_shadow(hit_point, normal, light, num_samples)
{
    if (num_samples == 1)
        return is_in_shadow(hit_point, light.position) ? 0.0 : 1.0;
    
    int lit_samples = 0;
    float sample_area = 2.0;  // 광원 샘플링 반경
    
    // 4x4 그리드 샘플링
    int samples_per_axis = (int)sqrt(num_samples);
    
    for (int i = 0; i < samples_per_axis; i++)
    {
        for (int j = 0; j < samples_per_axis; j++)
        {
            // 그리드 내 샘플 위치 (균등 분포)
            float u = (i + 0.5) / samples_per_axis;
            float v = (j + 0.5) / samples_per_axis;
            
            // 광원 중심 기준 오프셋
            vec3 offset = vec3(
                (u - 0.5) * sample_area,
                (v - 0.5) * sample_area,
                0
            );
            
            // 광원 방향에 수직인 평면에 오프셋 적용
            vec3 light_sample = add(light.position, offset);
            
            // Shadow ray 테스트
            if (!is_in_shadow(hit_point, light_sample, scene))
                lit_samples++;
        }
    }
    
    // 조명된 샘플 비율 반환 (0.0 ~ 1.0)
    return (float)lit_samples / num_samples;
}
```

**품질 설정**:
- **높은 품질**: 16 samples (4x4) - 정지 상태
- **낮은 품질**: 1 sample - 인터랙션 중

> **Shadow Offset LUT**: 실제 구현에서는 샘플 오프셋이 시작 시 LUT(`offset_lut`)에 사전 계산됩니다. 렌더링 중에는 매번 오프셋을 계산하지 않고 LUT에서 참조하여 성능을 향상시킵니다.

> **Shadow BVH Any-Hit**: 객체 수가 5개를 초과하는 장면에서는 그림자 광선 테스트에 BVH any-hit 순회를 사용합니다. 첫 번째 차폐 객체를 발견하면 즉시 반환하여 (closest-hit 불필요) 그림자 계산을 가속합니다.

### Shadow Acne 방지

교차점과 표면이 너무 가까워서 자기 자신과 교차하는 문제를 방지합니다.

**적응형 Shadow Bias**:

```c
float calculate_shadow_bias(normal, light_dir)
{
    // 표면 기울기에 따라 bias 조정
    float cos_angle = dot(normal, light_dir);
    
    // 기울어진 표면일수록 큰 bias 필요
    float base_bias = 0.001;
    float max_bias = 0.01;
    
    // cos_angle이 작을수록 (기울기 클수록) bias 증가
    float bias = base_bias + (1.0 - cos_angle) * max_bias;
    
    return bias;
}

vec3 get_shadow_ray_origin(hit_point, normal, light_dir)
{
    float bias = calculate_shadow_bias(normal, light_dir);
    return add(hit_point, scale(normal, bias));
}
```

## 🎨 색상 처리

### 색상 혼합

두 색상을 곱셈으로 혼합:

```c
vec3 multiply_color(vec3 c1, vec3 c2)
{
    return vec3(
        c1.x * c2.x / 255.0,
        c1.y * c2.y / 255.0,
        c1.z * c2.z / 255.0
    );
}
```

### 색상 클램핑

RGB 값을 [0, 255] 범위로 제한:

```c
vec3 clamp_color(vec3 color)
{
    return vec3(
        fmin(255.0, fmax(0.0, color.x)),
        fmin(255.0, fmax(0.0, color.y)),
        fmin(255.0, fmax(0.0, color.z))
    );
}
```

### 감마 보정 (선택)

선형 색공간을 디스플레이 색공간으로 변환:

```c
vec3 gamma_correct(vec3 color, float gamma)
{
    return vec3(
        pow(color.x / 255.0, 1.0 / gamma) * 255.0,
        pow(color.y / 255.0, 1.0 / gamma) * 255.0,
        pow(color.z / 255.0, 1.0 / gamma) * 255.0
    );
}
```

### 조명 캐싱

반복 계산을 피하기 위해 일부 값을 캐싱:

```c
typedef struct s_light_cache
{
    vec3    to_light;           // 정규화된 방향
    float   distance;           // 거리
    vec3    scaled_color;       // brightness 적용된 색상
}   t_light_cache;
```
