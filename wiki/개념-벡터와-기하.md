# 개념: 벡터와 기하

> 이 문서는 누구를 위한 것인가
> - 벡터 연산을 고등학교 수준으로만 들어봤거나 기억이 가물한 사람
> - 레이트레이싱 코드에서 내적/외적이 "왜" 나오는지 이해하고 싶은 사람
> - miniRT의 `t_vec3` API가 각각 무슨 일을 하는지 매핑하고 싶은 사람

## 1. 벡터 = "방향이 있는 화살표"

3D 공간의 점(point)이나 방향(direction)은 모두 세 개의 실수 `(x, y, z)` 로 표현합니다. miniRT에서는 `includes/common/vec3.h:17`의 `t_vec3`를 사용합니다.

```c
typedef struct s_vec3
{
    double  x;
    double  y;
    double  z;
}   t_vec3;
```

같은 자료형이지만 문맥에 따라 세 가지 의미로 쓰입니다.

- **점(point)**: 공간의 위치 (예: 구의 중심)
- **방향(direction)**: 크기는 보통 1로 정규화 (예: 광선 방향)
- **변위(displacement)**: 두 점의 차이 (예: `light - point`)

## 2. 기본 연산과 직관

### 덧셈/뺄셈 — `vec3_add`, `vec3_subtract`

```
A + B: 두 변위를 이어 붙이기
B - A: A에서 B로 가는 변위 (B = A + (B-A))
```

레이트레이싱에서 "점 P에서 광원 L로 향하는 방향"을 구하려면 `L - P` 를 계산합니다.

```c
t_vec3 to_light = vec3_subtract(light->position, hit->point);
```

### 스칼라 곱 — `vec3_multiply`

벡터의 길이를 바꿉니다. 광선의 원점에서 `t` 만큼 진행한 점은:

```c
t_vec3 p = vec3_add(ray->origin, vec3_multiply(ray->direction, t));
```

이 공식은 `src/spatial/intersect/intersect_object.c:51`처럼 코드 전반에서 반복됩니다.

### 내적(dot product) — `vec3_dot`

$a \cdot b = a_x b_x + a_y b_y + a_z b_z$ 를 계산합니다. 기하학적으로는 "두 벡터가 얼마나 같은 방향을 보는가"를 측정합니다.

- `dot(a, b) > 0`: 예각 (비슷한 방향)
- `dot(a, b) = 0`: 직각
- `dot(a, b) < 0`: 둔각 (반대 방향)

두 벡터 모두 길이 1이면 `dot`는 `cos(사잇각)` 과 같습니다. 이게 **디퓨즈 조명**의 핵심 공식입니다.

```c
// src/lighting/shading/shading.c:62
diffuse = vec3_dot(hit->normal, light_dir);
if (diffuse < 0) diffuse = 0;   // 뒷면은 어둡게
```

법선이 광원 방향을 정면으로 보면 1 (가장 밝음), 90도면 0, 뒤쪽이면 음수(어둡게 클램프).

### 외적(cross product) — `vec3_cross`

$a \times b$ 는 두 벡터에 **수직인 새 벡터**를 만듭니다. 길이는 두 벡터가 만드는 평행사변형 넓이.

miniRT에서 카메라의 "위쪽 벡터"를 만들 때 씁니다. `src/render/render_camera.c:35`:

```c
camera->cache.up = vec3_normalize(vec3_cross(camera->cache.right,
            camera->direction));
```

"오른쪽 × 앞" = "위". 또 범프맵의 tangent/bitangent 구성에도 사용됩니다.

### 크기(magnitude) — `vec3_magnitude`, 정규화 — `vec3_normalize`

크기는 벡터의 길이 $\sqrt{x^2+y^2+z^2}$. 정규화는 벡터를 그대로 방향만 유지한 채 길이 1로 바꾸는 것.

광선의 방향은 반드시 정규화해야 교차 계산 공식이 간단해집니다 (`src/render/render_camera.c:65`).

## 3. 기하체 방정식

miniRT가 다루는 네 가지 도형은 모두 "점의 집합"으로 표현됩니다.

### 구(Sphere)

중심 $C$, 반지름 $r$ 인 구 위의 점 $P$ 는:

> $|P - C|^2 = r^2$

즉 `vec3_dot(P - C, P - C) = r*r` 를 만족. miniRT는 반지름의 제곱(`radius_sq`)을 미리 저장해 제곱근을 피합니다 (`includes/common/objects.h:41`).

### 평면(Plane)

점 $P_0$ 를 지나고 법선이 $N$ 인 평면 위의 점 $P$ 는:

> $(P - P_0) \cdot N = 0$

평면 위의 모든 변위가 법선과 수직이라는 뜻. 광선과 평면 교차 판정은 "광선 방향이 법선과 수직이 아니면 반드시 만난다"입니다 (`src/spatial/intersect/intersect_object.c:76`의 `denom = dot(normal, direction)`).

### 실린더(Cylinder, 무한)

축 $\hat{a}$ 를 따라 중심 $C$ 를 지나는 반지름 $r$ 인 무한 실린더:

> $|(P - C) - ((P - C) \cdot \hat{a}) \hat{a}|^2 = r^2$

축 방향 성분을 제거한 반경 성분의 길이가 $r$ 이라는 뜻. miniRT는 여기에 "축 방향 투영이 `±half_height` 사이에 있어야 한다"를 추가해 유한 실린더를 만듭니다.

### 원뿔(Cone)

꼭짓점에서의 거리에 비례해 반경이 커지는 관계. 자세한 유도는 [심화: 광선-객체 교차 수학](심화-광선-객체-교차수학)을 참조.

## 4. miniRT `t_vec3` API 치트시트

| 함수 | 역할 | 위치 |
|------|------|------|
| `vec3_add` | A + B | `src/common/vec3.c` |
| `vec3_subtract` | A - B | 동상 |
| `vec3_multiply` | v * s | 동상 |
| `vec3_dot` | A · B | `src/common/vec3_ops.c` |
| `vec3_cross` | A × B | 동상 |
| `vec3_magnitude` | \|v\| | 동상 |
| `vec3_normalize` | v / \|v\| | 동상 |

파서가 방향 벡터를 읽을 때 항상 `vec3_normalize` 를 호출하는 이유는, 이후 교차 계산 공식이 "단위 벡터라고 가정"하기 때문입니다 (`src/scene/parser/parse_elements.c:77`).
