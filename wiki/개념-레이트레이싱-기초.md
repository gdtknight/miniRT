# 개념: 레이트레이싱 기초

> 이 문서는 누구를 위한 것인가
> - 3D 그래픽스를 처음 접하는 사람
> - miniRT가 "어떻게 그림이 나오는지" 전체 그림을 잡고 싶은 사람
> - 수식은 가볍게 훑되, 직관을 먼저 얻고 싶은 사람

## 1. 무엇을 그리는가

컴퓨터 그래픽스의 목표는 "3D 공간의 물체들을 평면 이미지에 그리는 것"입니다. 접근 방식은 크게 두 가지입니다.

- **래스터라이제이션(Rasterization)**: 삼각형(메시)을 화면에 투영해서 픽셀을 칠하는 방식. 게임 엔진이 사용.
- **레이트레이싱(Ray Tracing)**: 픽셀마다 "빛이 어디서 왔을까?"를 역으로 추적하는 방식. 영화 CG, 오프라인 렌더러가 사용.

miniRT는 **레이트레이싱** 방식입니다.

## 2. 핀홀 카메라 모델

현실의 카메라는 작은 구멍(핀홀)을 통해 빛이 들어와 필름에 상이 맺힙니다. miniRT도 이 모델을 흉내 냅니다.

```
             이미지 평면 (필름)
              ┌───────────┐
              │           │
              │     ×     │  ← 픽셀 하나
              │           │
              └───────────┘
                   ↑
                   │  "카메라 광선(ray)"
                   │
                  [ ]  ← 카메라(핀홀)
```

각 픽셀마다 카메라에서 **광선(ray)** 하나를 쏘아 씬으로 보냅니다. 광선은 "어느 물체에 맞는가?"를 묻는 질문입니다.

## 3. 씬·광선·교차·셰이딩

레이트레이싱 한 사이클은 네 단계로 나뉩니다.

1. **씬(Scene)**: 카메라, 조명, 물체들로 구성된 가상 세계. `.rt` 파일에 정의.
2. **광선(Ray) 생성**: 각 픽셀마다 카메라에서 해당 픽셀 방향으로 광선을 만듭니다.
3. **교차(Intersection)**: 광선과 모든 물체를 충돌 테스트하여 가장 가까운 접점을 찾습니다.
4. **셰이딩(Shading)**: 접점의 색을 계산합니다. 재질 색, 조명 방향, 그림자 여부를 섞어 최종 픽셀 값을 냅니다.

```
각 픽셀마다:
  ray = 카메라 → 픽셀
  hit = 교차(ray, 씬)
  if hit:
      color = 셰이딩(hit, 조명들)
  else:
      color = 검정
  put_pixel(x, y, color)
```

miniRT에서 이 루프는 `src/render/render.c:49`의 `render_pixel()`에 해당합니다.

## 4. 래스터와의 차이

| 항목 | 래스터 | 레이트레이싱 |
|------|--------|--------------|
| 순서 | 물체 → 픽셀 | 픽셀 → 물체 |
| 그림자 | 별도 기법 필요 | 자연스럽게 지원 (그림자 광선) |
| 반사/굴절 | 구현 복잡 | 광선을 재발사해서 처리 |
| 속도 | 매우 빠름 | 느림 (가속 구조 필요) |

miniRT는 **BVH(Bounding Volume Hierarchy)** 라는 공간 분할 트리로 "광선이 건드릴 가능성이 있는 물체만" 테스트해서 속도 문제를 완화합니다. 자세한 내용은 [개념: AABB와 공간분할](개념-AABB와-공간분할)을 참고하세요.

## 5. miniRT가 지원하는 범위

- 물체 종류: 구(sphere), 평면(plane), 실린더(cylinder), 원뿔(cone - 보너스)
- 조명: 점광원(point light) 여러 개 + 주변광(ambient)
- 그림자: 소프트 섀도우(stratified sampling)
- 재질: 단색, 체커보드 패턴, 범프 맵(법선 섭동)

반사/굴절은 구현하지 않았습니다.

## 6. 전체 파이프라인 한눈에

```
main() [src/main.c:132]
  ├── parse_scene()         .rt 파일 읽어 t_scene 채우기
  ├── build_scene_bvh()     공간 가속 구조 빌드
  ├── render_create()       MLX 윈도우 + 이미지 버퍼 준비
  └── mlx_loop()            이벤트 루프
        └── render_loop()   [src/render/render_loop.c:71]
              └── render_scene_to_buffer()
                    └── (픽셀 하나씩) render_pixel()
                          ├── create_camera_ray()
                          ├── trace_ray()      ← BVH + 교차 + 셰이딩
                          └── put_pixel_to_buffer()
```
