# 모듈: 렌더링

렌더링 루프, 카메라 레이 생성, 디바운스, 메트릭 수집을 담당하는 모듈입니다.

---

## 소스 파일

### Render (`src/render/`)

| 파일 | 역할 |
|------|------|
| `render.c` | `render_scene_to_buffer` -- 전체 씬 렌더링 |
| `render_trace.c` | `trace_ray` -- BVH/brute-force 분기 및 조명 적용 |
| `render_camera.c` | `create_camera_ray` -- 카메라 레이 생성 |
| `render_debounce.c` | 디바운스 상태 머신 |
| `render_debounce_timer.c` | 디바운스 타이머 유틸리티 |
| `render_loop.c` | `render_loop` -- 프레임 루프 콜백 |
| `render_flags_set.c` | 렌더 상태 플래그 헬퍼 |

### Metrics (`src/metrics/`)

| 파일 | 역할 |
|------|------|
| `metrics_frame.c` | 프레임 시간 측정 |
| `metrics_counters.c` | 레이/교차/BVH 카운터 갱신 |
| `metrics_calc.c` | FPS, BVH 효율 계산 |
| `metrics_shadow.c` | shadow 교차 테스트 카운터 |

## 렌더링 루프

`render_loop()`은 MiniLibX의 `mlx_loop_hook`에 등록되어 매 프레임 호출됩니다.

```
render_loop(render)
 |-- debounce_update()              // FSM 상태 전이
 |-- rebuild_bvh_if_dirty()         // BVH 재구축 (필요 시)
 |-- [RENDER_DIRTY] execute_render_pass()
 |    |-- metrics_start_frame()
 |    |-- render_scene_to_buffer(scene, render)
 |    |    |-- [full quality] render_pixel() per pixel
 |    |    |    |-- create_camera_ray()
 |    |    |    |-- trace_ray()
 |    |    |    +-- put_pixel_to_buffer()
 |    |    +-- [low quality] render_low_quality()
 |    |         |-- create_camera_ray()
 |    |         |-- trace_ray()
 |    |         +-- draw_pixel_block()   // 블록 단위 채우기
 |    |-- metrics_end_frame()
 |    +-- mlx_put_image_to_window()
 |-- [rendered] keyguide.dirty = 1
 +-- [HUD visible && (dirty || rendered)]
      |-- hud_render()
      +-- keyguide_render()
```

## trace_ray

```c
t_color trace_ray(t_scene *scene, t_ray *ray)
```

1. `metrics_add_ray()` -- 레이 카운터 증가
2. 교차 검사:
   - BVH 활성화: `bvh_intersect()` + plane 별도 루프
   - BVH 비활성화: 전체 오브젝트 순회 (brute-force)
3. Hit 발생 시 `apply_lighting()` -> 색상 반환
4. Miss 시 검정색 `(0, 0, 0)` 반환

BVH 경로에서는 plane이 BVH 트리에 포함되지 않으므로 별도 루프로 교차 검사합니다. brute-force 경로에서는 plane을 포함한 모든 오브젝트를 순차 순회합니다.

## 카메라 레이 생성

`create_camera_ray(camera, x, y)`:

1. `t_camera_cache`의 dirty 플래그 확인
   - 유효하면 캐싱된 basis 벡터(right, up) 사용
   - 무효하면 `camera->direction`에서 right/up 벡터 계산 후 캐시 갱신
2. 뷰포트 좌표 `(x, y)` -> 정규화된 화면 좌표로 변환
3. basis 벡터(forward, right, up) 조합으로 레이 방향 계산
4. `inv_dir` (1/direction) 사전 계산 -- AABB slab method 교차 최적화에 사용

카메라 위치나 방향이 변경되지 않는 한 basis 벡터를 재계산하지 않아 불필요한 연산을 방지합니다.

## 품질 모드

| 모드 | 조건 | 렌더링 방식 | 용도 |
|------|------|------------|------|
| Full Quality (FQ) | `RENDER_LOW_QUALITY` 플래그 없음 | 픽셀 개별 렌더링 | 정지 상태, 최종 렌더링 |
| Low Quality (LQ) | `RENDER_LOW_QUALITY` 플래그 있음 | 블록 단위 렌더링 (2x2) | 인터랙션 중 빠른 피드백 |

- LQ 모드에서는 블록 내 모든 픽셀을 대표 픽셀의 색상으로 채움
- 인터랙션(키 입력) 시 LQ로 전환하여 빠른 피드백 제공
- 디바운스 타이머 만료 후 FQ로 재렌더링

## 디바운스

4-상태 FSM으로 인터랙션 중 렌더링 품질과 타이밍을 제어합니다.

```
IDLE --(입력)--> ACTIVE --(150ms 만료)--> FINAL --(FQ 렌더 완료)--> COOLDOWN --(350ms)--> IDLE
                  ^  |                     |                                               |
                  |  +--(재입력: 리셋)      |                                               |
                  |                        +----------(재입력 시)----------------------------+
                  +-----------------------------(재입력 시)----------------------------------+
```

| 상태 | 설명 |
|------|------|
| IDLE | 대기 상태. 입력 발생 시 ACTIVE로 전이 |
| ACTIVE | 디바운스 타이머 동작 중 (150ms). 추가 입력 시 타이머 리셋하여 대기 연장 |
| FINAL | FQ 렌더 대기 상태. ACTIVE->FINAL 전이 시 `RENDER_LOW_QUALITY` 해제 + `RENDER_DIRTY` 설정 |
| COOLDOWN | FQ 렌더 완료 후 350ms 쿨다운. 재입력 시 ACTIVE로 복귀 |

### LQ 프리뷰 스로틀

`debounce_on_input()` 호출 시 상태와 무관하게 `debounce_check_preview_throttle()`로 50ms 간격 제한하여 LQ 프리뷰를 트리거합니다. 이를 통해 연속 키 입력 시에도 과도한 LQ 렌더링을 방지합니다.

## 메트릭 수집

`t_metrics` 구조체에 프레임별로 수집하는 지표:

| 카테고리 | 지표 | 설명 |
|---------|------|------|
| Frame | `render_time_us` | 프레임 렌더링 시간 (마이크로초) |
| Frame | `fps` | 초당 프레임 수 |
| Ray | `rays_traced` | 추적된 레이 수 |
| Ray | `intersect_tests` | primary 교차 테스트 수 |
| Ray | `shadow_intersect_tests` | shadow 교차 테스트 수 |
| BVH | `nodes_visited` | 방문한 BVH 노드 수 |
| BVH | `tests_skipped` | AABB 스킵된 테스트 수 |

- 메트릭은 HUD에 실시간 표시
- `RENDER_ENABLE_METRICS_PRINT` 플래그 설정 시 콘솔에도 출력
