# 모듈: 렌더링

렌더링 루프, 카메라 레이 생성, 디바운스, MLX 창/픽셀 관리, 메트릭 수집을 담당하는 모듈입니다.

## 소스 파일

|------|------|
| `render.c` | `render_scene_to_buffer` — 전체 씬 렌더링 |

## 렌더링 루프

`render_loop()`은 MiniLibX의 `mlx_loop_hook`에 등록되어 매 프레임 호출됩니다.

```
render_loop(render)
 ├── debounce_update()              // FSM 상태 전이
 ├── rebuild_bvh_if_dirty()         // BVH 재구축 (필요 시)
 ├── [RENDER_DIRTY] execute_render_pass()
 │    ├── metrics_start_frame()
 │    ├── render_scene_to_buffer(scene, render)
 │    │    ├── [full quality] 픽셀당 render_pixel()
 │    │    │    ├── create_camera_ray()
 │    │    │    ├── trace_ray()
 │    │    │    └── put_pixel_to_buffer()
 │    │    └── [low quality] 2x2 블록 단위 렌더
 │    ├── metrics_end_frame()
 │    └── mlx_put_image_to_window()
 ├── hud_render()
 └── keyguide_render()
```

## trace_ray

```c
t_color trace_ray(t_scene *scene, t_ray *ray)
```

1. `metrics_add_ray()` — 레이 카운터 증가
2. 교차 검사:
   - BVH 활성화 → `bvh_intersect()` + plane 별도 선형 테스트
   - BVH 비활성화 → 전체 오브젝트 순회 (brute-force)
3. Hit → `apply_lighting()`
4. Miss → 검정색 `(0, 0, 0)`

BVH 경로에서 plane은 BVH 트리에 포함되지 않으므로 별도 루프로 교차 검사합니다.

## 카메라 레이 생성

`create_camera_ray(camera, x, y)`:

1. `t_camera_cache`의 dirty 플래그 확인
   - 유효 → 캐시된 right/up 사용
   - 무효 → `camera->direction`에서 재계산 및 캐시 갱신
2. 뷰포트 좌표 → 정규화 화면 좌표
3. basis (forward, right, up) 조합으로 레이 방향 계산
4. `inv_dir` (1/direction) 사전 계산 (AABB slab 교차용)

카메라가 움직이지 않는 한 프레임당 basis 재계산을 방지합니다.

## 디바운스 FSM

4-상태로 인터랙션 중 품질/타이밍을 제어합니다.

```
IDLE --(입력)--> ACTIVE --(150ms 만료)--> FINAL --(FQ 완료)--> COOLDOWN --(350ms)--> IDLE
```

| 상태 | 설명 |
|------|------|
| IDLE | 대기. 입력 발생 시 ACTIVE로 전이 |
| ACTIVE | 150ms 디바운스. 추가 입력 시 타이머 리셋 |
| FINAL | `RENDER_LOW_QUALITY` 해제 + `RENDER_DIRTY` 설정, FQ 렌더 |
| COOLDOWN | FQ 완료 후 350ms. 재입력 시 ACTIVE로 복귀 |

### LQ 프리뷰 스로틀

`debounce_on_input()` 호출 시 상태와 무관하게 `debounce_check_preview_throttle()`로 50ms 간격 제한하여 LQ 프리뷰를 트리거합니다.

## 메트릭 수집

`t_metrics` (`includes/metrics.h`)로 프레임별 지표를 수집:

| 카테고리 | 지표 | 설명 |
|---------|------|------|
| Frame | `render_time_us` | 프레임 렌더 시간 (µs) |
| Frame | `fps` | 초당 프레임 수 |
| Ray | `rays_traced` | 추적된 레이 수 |
| Ray | `intersect_tests` | primary 교차 테스트 수 |
| Ray | `shadow_intersect_tests` | shadow 교차 테스트 수 |
| BVH | `nodes_visited` | 방문 BVH 노드 수 |
| BVH | `tests_skipped` | AABB 스킵된 테스트 수 |

- HUD에 실시간 표시
- `RENDER_ENABLE_METRICS_PRINT` 플래그 설정 시 콘솔 출력
