# 모듈: 공간가속

BVH(Bounding Volume Hierarchy) 공간 가속 구조의 구축, 순회, 시각화를 담당하는 모듈입니다. 소스는 `src/spatial/`의 네 서브디렉토리(`intersect/`, `aabb/`, `bvh/`, `debug/`)로 분리되어 있습니다.

---

## BVH 구축

### Plane 분리

`build_scene_bvh()`에서 plane을 BVH 트리에서 제외합니다:

- Plane의 AABB는 `[-1e6, 1e6]^3`으로 극도로 넓어 BVH 품질 저하
- Plane 인덱스를 `t_plane_refs`에 별도 저장
- Bounded 오브젝트(sphere, cylinder, cone)만 트리에 포함

### bvh_build_recursive 흐름

```
bvh_build_recursive(objects, count, scene, depth)
 ├── count <= 2 || depth > 20 → create_leaf_node()
 ├── compute_bounds()            // 전체 오브젝트 AABB 합산
 ├── choose_split_axis()         // 가장 긴 축
 ├── calculate_split_position()  // AABB 중심
 ├── partition_objects()
 └── create_split_node()
      ├── bvh_build_recursive(left, ...)
      └── bvh_build_recursive(right, ...)
```

- **Split axis**: 가장 긴 축 (x/y/z)
- **Split position**: `(bounds.min + bounds.max) / 2.0`
- **Leaf 조건**: 오브젝트 ≤ 2 또는 깊이 > 20

### 오브젝트별 AABB

| 오브젝트 | AABB |
|---------|------|
| Sphere | `center ± radius` |
| Cylinder | `center ± (radius + |half_axis|)` |
| Cone | `center ± (radius + |half_axis|)` |
| Plane | 제외 (별도 관리) |

## AABB 교차

```c
int aabb_intersect(t_aabb box, t_ray ray, double *t_min, double *t_max)
```

Slab method:

1. 각 축별 `t0`, `t1` 계산 (`safe_slab_axis`)
2. `inv_dir`로 나눗셈을 곱셈으로 대체
3. 모든 축의 `[t0, t1]` 교집합이 비어있지 않으면 교차

`safe_slab_axis`는 레이가 축에 평행(`inv_dir`이 무한대)한 경우를 안전하게 처리합니다.

## Primary ray 순회

```
bvh_node_intersect(node, ray, hit, scene)
 ├── aabb_intersect() miss → return 0
 ├── leaf → 각 오브젝트에 intersect_object()
 └── internal node
      ├── ordered traversal (ray 방향 기준 가까운 자식 우선)
      ├── first child intersect
      ├── t_max pruning: second child AABB.tmin > hit.distance → skip
      └── second child intersect
```

---

## Shadow any-hit

```
bvh_any_hit(bvh, ray, max_dist, scene)
 ├── BVH 순회 (bounded 오브젝트만)
 └── 첫 번째 hit 즉시 return 1 (early exit)
```

- `SHADOW_BVH_THRESHOLD = 5`: 오브젝트 5개 초과이면 BVH, 이하이면 brute-force
- BVH에 없는 plane은 별도 테스트

## Plane 분리 효과

S4 씬 (7 sphere + 7 cylinder + 3 plane):

| 지표 | plane 포함 BVH | plane 분리 BVH |
|------|---------------|---------------|
| BVH skip rate | 32.9% | **82.0%** |
| Shadow tests | 369.6M | **83.7M** |
| Frame time | 25.6s | **6.1s** |

Plane의 `[-1e6, 1e6]^3` AABB가 BVH 트리 분할을 무력화하여, 분리만으로 프레임 시간이 약 4.2배 단축되었습니다.

## BVH 시각화

```bash
./miniRT scenes/valid/valid_scene_comprehensive.rt --bvh-vis
```

`src/spatial/debug/`의 `bvhd_*` 파일들이 트리를 재귀 순회하며 깊이, 분할 축, AABB 범위, 리프 오브젝트 목록 및 통계(총 노드 수, 리프 수, 최대 깊이)를 출력합니다.

```
BVH Tree (depth=0, axis=X)
├── [L] depth=1, axis=Y, bounds=[...]
│   ├── [L] LEAF: sp-1, sp-2
│   └── [R] LEAF: sp-3
└── [R] depth=1, axis=Z
    └── LEAF: cy-1, cy-2
```
