## BVH 구축

### Plane 분리

`scene_build_bvh()`에서 plane을 BVH 트리에서 제외합니다:

- Plane의 AABB는 `[-1e6, 1e6]^3`으로 극도로 넓어 BVH 트리 품질을 저하
- Plane 인덱스를 `t_plane_refs`에 별도 저장
- Bounded 오브젝트(sphere, cylinder, cone)만 BVH 트리에 포함

### bvh_build_recursive 흐름

```
bvh_build_recursive(objects, count, scene, depth)
 |-- count <= 2 || depth > 20 -> create_leaf_node()
 |-- compute_bounds()           // 전체 오브젝트 AABB 합산
 |-- choose_split_axis()        // 가장 긴 축 선택
 |-- calculate_split_position() // AABB 중심점 기준 분할점
 |-- partition_objects()        // 분할점 기준 좌/우 분리
 +-- create_split_node()
      |-- bvh_build_recursive(left, ...)
      +-- bvh_build_recursive(right, ...)
```

- **Split axis**: AABB의 가장 긴 축 (x/y/z)
- **Split position**: AABB 중심점 기준 `(bounds.min + bounds.max) / 2.0`
- **Leaf 조건**: 오브젝트 수 <= 2 또는 깊이 > 20이면 리프 노드 생성

### 오브젝트별 AABB 계산

| 오브젝트 | AABB 계산 방식 |
|---------|---------------|
| Sphere | `center +/- radius` (각 축) |
| Cylinder | `center +/- (radius + |half_axis|)` (각 축별) |
| Cone | `center +/- (radius + |half_axis|)` (cylinder와 동일 패턴) |
| Plane | 제외 (별도 관리) |

## AABB 교차

```c
int aabb_intersect(t_aabb box, t_ray ray, double *t_min, double *t_max)
```

Slab method를 사용합니다:

1. 각 축(x, y, z)별로 `t0`, `t1` 계산 (`safe_slab_axis`)
2. `inv_dir` (1/direction, 레이 생성 시 사전 계산)로 나눗셈 대체
3. 모든 축의 `[t0, t1]` 구간을 `tmin`, `tmax`에 누적
4. 교집합이 비어있지 않으면(`tmin <= tmax && tmax > 0`) 교차

`safe_slab_axis`는 `inv_dir`이 무한대(레이가 축에 평행)인 경우를 안전하게 처리합니다.

## Primary ray 순회

```
bvh_node_intersect(node, ray, hit, scene)
 |-- aabb_intersect() -> miss -> return 0
 |-- leaf -> intersect_object() per object
 +-- internal node
      |-- ordered traversal (ray 방향 기준 가까운 자식 먼저)
      |-- first child intersect
      |-- t_max pruning: second child AABB.tmin > current hit.distance -> skip
      +-- second child intersect
```

- **Ordered traversal**: `ray.direction[split_axis]`가 양수면 left 먼저, 음수면 right 먼저. 가까운 자식을 먼저 탐색하여 early pruning 확률을 높임
- **t_max pruning**: 이미 찾은 hit보다 먼 노드는 탐색하지 않음. 두 번째 자식의 AABB tmin이 현재 hit distance보다 크면 스킵

## Shadow any-hit

```
bvh_intersect_any(bvh, ray, max_dist, scene)
 |-- BVH 순회 (bounded 오브젝트만)
 +-- 첫 번째 hit 발견 시 즉시 return 1 (early exit)
```

- 그림자 판정은 "차폐 여부"만 필요하므로 closest-hit가 아닌 아무 교차에서 즉시 종료
- 일반 BVH 순회(`bvh_intersect`)보다 빠름
- `SHADOW_BVH_THRESHOLD = 5`: 오브젝트 5개 초과이면 BVH any-hit 사용, 이하이면 brute-force
- BVH에 포함되지 않는 plane은 `check_plane_shadow()`로 별도 테스트

## Plane 분리 효과

S4 씬 (7 sphere + 7 cylinder + 3 plane) 기준 벤치마크:

| 지표 | plane 포함 BVH | plane 분리 BVH |
|------|---------------|---------------|
| BVH skip rate | 32.9% | **82.0%** |
| Shadow tests | 369.6M | **83.7M** |
| Frame time | 25.6s | **6.1s** |

Plane의 `[-1e6, 1e6]^3` AABB가 BVH 트리의 모든 분할을 무력화했기 때문에, plane을 분리하는 것만으로 BVH skip rate가 32.9%에서 82.0%로 개선되고, 프레임 시간이 약 4.2배 단축됩니다.

## BVH 시각화

`--bvh-vis` 플래그로 BVH 트리 구조를 콘솔에 출력합니다.

### 사용법

```bash
./miniRT --bvh-vis scenes/valid/valid_scene_comprehensive.rt
```

### 출력 예시

```
BVH Tree (depth=0, axis=X)
+-- [L] depth=1, axis=Y, bounds=[...]
|   +-- [L] LEAF: sp-1, sp-2
|   +-- [R] LEAF: sp-3
+-- [R] depth=1, axis=Z
    +-- LEAF: cy-1, cy-2
```

`src/bvh_vis/` 모듈이 트리를 재귀적으로 순회하면서 각 노드의 깊이, 분할 축, AABB 범위, 리프 노드의 오브젝트 목록 등을 출력합니다. BVH 통계(총 노드 수, 리프 수, 최대 깊이 등)도 함께 표시됩니다.
