# 씬 파일 형식

`.rt` 씬 파일은 렌더링할 3D 장면을 정의하는 텍스트 파일입니다.

---

## 기본 규칙

| 항목 | 설명 |
|------|------|
| 파일 확장자 | `.rt` |
| 인코딩 | ASCII |
| 요소 정의 | 한 줄에 하나의 요소 |
| 주석 | `#`으로 시작하는 줄은 무시 (라인 중간 주석은 미지원) |
| 빈 줄 | 무시 |
| 최대 줄 길이 | 4096자 |
| 구분자 | 요소 간: 공백 또는 탭 (여러 개 가능), 좌표/색상 간: 쉼표 `,` (공백 없음) |
| 대소문자 | 식별자는 대소문자 구분 (`A`, `C`, `L`, `sp`, `pl`, `cy`, `co`만 유효) |

---

## 필수 요소

### A -- 주변광 (Ambient Light)

씬에 정확히 1개 필요합니다.

```
A  <ratio>  <R,G,B>
```

| 파라미터 | 타입 | 범위 | 설명 |
|---------|------|------|------|
| ratio | double | 0.0 ~ 1.0 | 주변광 강도 |
| R,G,B | int,int,int | 0 ~ 255 | 주변광 색상 |

예시:
```rt
A  0.2  255,255,255
A  0.3  100,100,200
```

### C -- 카메라 (Camera)

씬에 정확히 1개 필요합니다.

```
C  <x,y,z>  <nx,ny,nz>  <fov>
```

| 파라미터 | 타입 | 범위 | 설명 |
|---------|------|------|------|
| x,y,z | double,double,double | 제한 없음 | 카메라 위치 |
| nx,ny,nz | double,double,double | -1.0 ~ 1.0 각 성분 | 시선 방향 (자동 정규화) |
| fov | int | 1 ~ 179 | 수평 시야각 (도) |

예시:
```rt
C  0,0,-15  0,0,1  70
C  10,5,10  -1,0,-1  90
```

- 방향 벡터는 자동 정규화됨
- 영벡터 (0,0,0)는 에러

### L -- 조명 (Light)

최소 1개, 최대 MAX_LIGHTS개까지 정의할 수 있습니다.

```
L  <x,y,z>  <brightness>  <R,G,B>
```

| 파라미터 | 타입 | 범위 | 설명 |
|---------|------|------|------|
| x,y,z | double,double,double | 제한 없음 | 광원 위치 |
| brightness | double | 0.0 ~ 1.0 | 밝기 |
| R,G,B | int,int,int | 0 ~ 255 | 광원 색상 |

예시:
```rt
L  -10,10,10  0.7  255,255,255
L  0,20,0  1.0  255,200,150
```

- 초과 시 `PARSE_ERR_OVERFLOW` 에러 발생

## 오브젝트 요소

씬에 최소 1개 이상의 오브젝트가 필요합니다.

### sp -- 구 (Sphere)

```
sp  <x,y,z>  <diameter>  <R,G,B>
```

| 파라미터 | 타입 | 범위 | 설명 |
|---------|------|------|------|
| x,y,z | double,double,double | 제한 없음 | 구 중심 |
| diameter | double | > 0 | 지름 |
| R,G,B | int,int,int | 0 ~ 255 | 색상 |

예시:
```rt
sp  0,0,0  12.6  255,0,0
sp  5,5,-5  5  0,255,0
```

### pl -- 평면 (Plane)

```
pl  <x,y,z>  <nx,ny,nz>  <R,G,B>
```

| 파라미터 | 타입 | 범위 | 설명 |
|---------|------|------|------|
| x,y,z | double,double,double | 제한 없음 | 평면 위의 한 점 |
| nx,ny,nz | double,double,double | -1.0 ~ 1.0 각 성분 | 법선 방향 (자동 정규화) |
| R,G,B | int,int,int | 0 ~ 255 | 색상 |

예시:
```rt
pl  0,-10,0  0,1,0  200,200,200
pl  0,0,-20  0,0,1  150,150,150
```

### cy -- 원기둥 (Cylinder)

```
cy  <x,y,z>  <nx,ny,nz>  <diameter>  <height>  <R,G,B>
```

| 파라미터 | 타입 | 범위 | 설명 |
|---------|------|------|------|
| x,y,z | double,double,double | 제한 없음 | 중심 위치 |
| nx,ny,nz | double,double,double | -1.0 ~ 1.0 각 성분 | 축 방향 (자동 정규화) |
| diameter | double | > 0 | 지름 |
| height | double | > 0 | 높이 |
| R,G,B | int,int,int | 0 ~ 255 | 색상 |

예시:
```rt
cy  0,0,0  0,1,0  5  10  0,255,0
cy  5,0,0  1,0,0  3  8  255,0,255
```

### co -- 원뿔 (Cone)

```
co  <x,y,z>  <nx,ny,nz>  <diameter>  <height>  <R,G,B>
```

| 파라미터 | 타입 | 범위 | 설명 |
|---------|------|------|------|
| x,y,z | double,double,double | 제한 없음 | 중심 (높이 중앙) |
| nx,ny,nz | double,double,double | -1.0 ~ 1.0 각 성분 | 축 방향 (자동 정규화, center에서 apex 방향) |
| diameter | double | > 0 | 밑면 지름 |
| height | double | > 0 | 높이 |
| R,G,B | int,int,int | 0 ~ 255 | 색상 |

예시:
```rt
co  0,0,0  0,1,0  4  8  255,128,0
co  5,0,0  1,0,0  3  8  255,0,255
```

## 보너스 옵션

오브젝트(sp, pl, cy, co)의 색상 뒤에 선택적으로 추가할 수 있습니다.

### checker -- 체커보드 패턴

`checker:R,G,B` 형식으로 보조 색상을 지정하면 오브젝트 표면에 체커보드 패턴이 적용됩니다.

```rt
sp  0,0,0  6  255,0,0  checker:0,0,0
pl  0,-5,0  0,1,0  200,200,200  checker:100,100,100
```

- R,G,B: 보조 색상 (0 ~ 255). 기본 색상과 교대로 패턴 생성

### bump -- 범프맵

`bump:파일경로` 형식으로 XPM 범프맵 파일을 지정하면 법선 교란으로 표면 요철 효과가 적용됩니다.

```rt
sp  0,0,0  6  255,0,0  bump:texture.xpm
```

- XPM 형식 파일만 지원

### 옵션 조합

두 옵션은 동시에 사용할 수 있습니다:

```rt
sp  0,0,0  6  255,0,0  checker:0,0,0  bump:texture.xpm
```

## 유효성 검증

### 값 범위 요약

| 파라미터 | 범위 |
|---------|------|
| 좌표 (x,y,z) | 제한 없음 |
| 방향 벡터 (nx,ny,nz) | -1.0 ~ 1.0 각 성분 (영벡터 불가) |
| 색상 (R,G,B) | 0 ~ 255 (정수) |
| ratio / brightness | 0.0 ~ 1.0 |
| FOV | 1 ~ 179 (정수) |
| diameter | > 0 |
| height | > 0 |

### 구조 규칙

| 규칙 | 설명 |
|------|------|
| A (주변광) | 정확히 1개 필수. 중복 시 에러 |
| C (카메라) | 정확히 1개 필수. 중복 시 에러 |
| L (조명) | 최소 1개, 최대 MAX_LIGHTS개 |
| 오브젝트 | 최소 1개 이상 필요 |
| 방향 벡터 | 자동 정규화. 영벡터 (0,0,0)는 에러 |

## 예제 씬

### 최소 씬

```rt
A  0.2  255,255,255
C  0,0,-15  0,0,1  70
L  0,8,-8  0.7  255,255,255
sp  0,0,0  6  255,0,0
```

### 종합 씬 (다중 오브젝트)

```rt
# 환경 설정
A  0.15  255,255,255

# 카메라
C  0,5,-20  0,-0.1,1  70

# 조명
L  -10,15,-5  0.8  255,255,255

# 바닥 평면
pl  0,-2,0  0,1,0  180,180,180

# 구
sp  -4,0,0  4  255,0,0
sp  0,0,0  4  0,255,0
sp  4,0,0  4  0,0,255

# 원기둥
cy  0,-2,5  0,1,0  2  6  255,255,0

# 원뿔 (보너스 옵션 적용)
co  -6,0,8  0,1,0  3  5  255,128,0  checker:0,0,0
```

## 에러 메시지

파싱 에러 시 `Error` + 줄 번호 + 에러 내용이 stderr로 출력됩니다.

| 상황 | 메시지 예시 |
|------|-----------|
| 파일 확장자 오류 | `Error: Invalid file extension (expected .rt)` |
| 형식 오류 | `Error: line 3 (A): Invalid format` |
| 값 범위 초과 | `Error: line 5 (sp): Value out of range` |
| 필수 요소 누락 | `Error: Missing required element: Camera` |
| 중복 정의 | `Error: line 7 (A): Duplicate element` |
| 알 수 없는 요소 | `Error: line 4: Unknown element type` |
| 광원 수 초과 | `PARSE_ERR_OVERFLOW` |
| 좌표에 공백 혼입 | `Error: line N: Invalid format` |
| 색상에 쉼표 누락 | `Error: line N: Invalid format` |
