|---------|------|

## 빌드

### 저장소 클론

```bash
# 서브모듈(libft) 포함 클론
git clone --recursive https://github.com/gdtknight/miniRT.git
cd miniRT
```

서브모듈 누락 시:
```bash
git submodule update --init --recursive
```

### 의존성 설치 (Linux)

```bash
sudo apt-get update
sudo apt-get install libx11-dev libxext-dev libbsd-dev
```

### 빌드 실행

```bash
make
```

### 빌드 타겟

| 타겟 | 설명 |
|------|------|
| `all` (기본) | libft -> MiniLibX -> miniRT 순차 빌드 |
| `clean` | 오브젝트 파일 삭제 (build/) |
| `fclean` | clean + 실행 파일 + MiniLibX/libft 정리 |
| `re` | fclean -> all (전체 재빌드) |
| `bonus` | `all`과 동일 (보너스 기능이 메인 바이너리에 포함) |
| `norm` | norminette 검사 (src/ + includes/) |

### 컴파일/링크 플래그

- 컴파일: `-Wall -Wextra -Werror`
- 링크 (Linux): `-lmlx -lft -lXext -lX11 -lm`
- 링크 (macOS): `-lmlx -lft -framework OpenGL -framework AppKit -lm`

## 실행

### 기본 실행

```bash
./miniRT scenes/valid/valid_smoke_simple.rt
```

### BVH 시각화 모드

BVH 트리 구조를 콘솔에 출력합니다. `--bvh-vis` 플래그는 씬 파일 앞뒤 어느 위치에도 올 수 있습니다.

```bash
./miniRT scenes/valid/valid_scene_comprehensive.rt --bvh-vis
```

### 보조 스크립트 (`scripts/`)

```bash
bash scripts/validate_norminette.sh   # norminette 검사
bash scripts/test_miniRT.sh           # 기본 실행 테스트
bash scripts/test_scenes.sh           # 씬 파일 검증
bash scripts/bench.sh                 # 벤치마크
```

메모리 검사(Linux):

```bash
valgrind --suppressions=miniRT.supp --leak-check=full \
    ./miniRT scenes/valid/valid_smoke_simple.rt
```

`miniRT.supp`는 유저 코드가 해제할 수 없는 X11/XCB/MiniLibX "still reachable" 누수를 필터링합니다.

## 프로젝트 의존성

### libft (서브모듈)

`lib/libft/`에 git 서브모듈로 관리됩니다. `make` 시 자동 빌드됩니다.

주요 사용 함수: `ft_atof`, `ft_atoi`, `ft_strlcpy`, `ft_memset`, `ft_strcmp` 등

### MiniLibX

- macOS: `lib/minilibx-macos/` (AppKit/OpenGL 기반)
- Linux: `lib/minilibx-linux/` (X11 기반)

`make` 시 자동 빌드됩니다. OS 감지는 Makefile에서 `uname -s`로 자동 수행됩니다.

### 수학 라이브러리

`-lm` 플래그로 링크됩니다. `sin`, `cos`, `sqrt`, `pow` 등 수학 함수를 사용합니다.

## 문제 해결

### "mlx.h: No such file or directory"

MinilibX 서브모듈이 초기화되지 않았습니다.

```bash
git submodule update --init --recursive
make re
```

### "X11/Xlib.h: No such file or directory" (Linux)

X11 개발 라이브러리가 설치되지 않았습니다.

```bash
sudo apt-get install libx11-dev libxext-dev libbsd-dev
make re
```

### Segmentation Fault

1. 씬 파일 형식이 올바른지 확인
2. 모든 법선 벡터가 정규화되어 있는지 확인 (각 성분의 절대값이 1 이하)
3. 지름/높이 등이 양수인지 확인

```bash
# 메모리 검사 (Linux)
valgrind --leak-check=full ./miniRT scenes/valid/valid_smoke_simple.rt
```

### "Error: mlx_init failed" (Linux)

X11 서버가 실행 중이지 않거나 DISPLAY 환경 변수가 설정되지 않았습니다.

```bash
echo $DISPLAY
export DISPLAY=:0
```

### 창이 열리지 않음 (macOS)

시스템 환경설정 > 보안 및 개인정보 보호 > 접근성에서 터미널 앱 권한을 확인하세요.
