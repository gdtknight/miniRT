# 모듈: 파서

`.rt` 씬 파일을 파싱하여 `t_scene` 구조체를 구축하는 모듈입니다. 소스는 `src/scene/parser/`에 위치하며 공개 헤더는 `includes/scene/parser.h`입니다.

---

## 소스 파일

| 파일 | 역할 |
|------|------|
| `parser.c` | 파싱 진입점 (`parse_scene`) |
| `parser_dispatch.c` | 요소 식별자별 분기 (`dispatch_element`) |
| `parser_utils.c` | 확장자 검증 등 유틸리티 |
| `parse_elements.c` | A (ambient), C (camera), L (light) 파싱 |
| `parse_objects.c` | sp (sphere), pl (plane) 파싱 |
| `parse_cylinder.c` | cy (cylinder) 파싱 |
| `parse_cone.c` | co (cone) 파싱 |
| `parse_bonus_options.c` | `checker:` / `bump:` 옵션 파싱 |
| `parse_number.c` | double / int 파싱 |
| `parse_validation_strict.c` | 벡터/색상 strict 파싱 + 유효성 검증 |
| `parse_vector_validation.c` | 벡터 범위 검증, 방향 벡터 정규화 |
| `parse_line_reader.c` | 버퍼 기반 라인 리더 (GNL 대체) |
| `parse_error.c` | 에러 컨텍스트 관리 및 메시지 매핑 |

---

## 파싱 흐름

```
parse_scene(filename, scene)
 ├── validate_extension()      # .rt 확장자 확인
 ├── open()                    # 파일 오픈
 ├── line_reader_init()        # 라인 리더 초기화
 ├── line_reader_next() 루프   # 라인 단위 읽기
 │    └── dispatch_element()   # 식별자별 분기
 │         ├── A → parse_ambient()
 │         ├── C → parse_camera()
 │         ├── L → parse_light()        (MAX_LIGHTS까지 허용)
 │         ├── sp → parse_sphere()      → parse_bonus_options()
 │         ├── pl → parse_plane()       → parse_bonus_options()
 │         ├── cy → parse_cylinder()    → parse_bonus_options()
 │         └── co → parse_cone()        → parse_bonus_options()
 ├── validate_scene()          # 필수 요소 확인
 └── close()
```

## 에러 코드

`t_parse_result` 열거형 (`includes/scene/parser.h`):

| 코드 | 의미 |
|------|------|
| `PARSE_OK` | 성공 |
| `PARSE_ERR_FORMAT` | 형식 오류 |
| `PARSE_ERR_RANGE` | 값 범위 초과 |
| `PARSE_ERR_COMPONENT_COUNT` | 컴포넌트 수 불일치 |
| `PARSE_ERR_DUPLICATE` | 필수 요소 중복 (A, C) |
| `PARSE_ERR_LINE_TOO_LONG` | 라인 길이 초과 (4096) |
| `PARSE_ERR_ZERO_VECTOR` | 영벡터 (방향 벡터) |
| `PARSE_ERR_TRAILING_TOKEN` | 줄 끝에 불필요한 토큰 |
| `PARSE_ERR_UNKNOWN_ELEMENT` | 알 수 없는 식별자 |
| `PARSE_ERR_NUMBER_FORMAT` | 숫자 형식 오류 |
| `PARSE_ERR_MISSING_ELEMENT` | 필수 요소 누락 |
| `PARSE_ERR_IO` | 파일 I/O 에러 |
| `PARSE_ERR_OVERFLOW` | 요소 수 초과 (MAX_LIGHTS) |

## 라인 리더

`t_line_reader`는 4096 바이트 버퍼로 라인 단위 파일을 읽습니다. GNL 대신 직접 구현하여 버퍼 오버플로 방지 및 strict한 line-too-long 감지를 수행합니다.

---

## 유효성 검증

### 값 범위

| 항목 | 범위 |
|------|------|
| ratio / brightness | 0.0 ~ 1.0 |
| FOV | 1 ~ 179 (정수) |
| 색상 (R, G, B) | 0 ~ 255 |
| 방향 벡터 | 각 성분 -1.0 ~ 1.0, 영벡터 거부 후 정규화 |
| 지름 / 높이 | 양수 |

### 구조적 규칙

- A, C는 정확히 1개 (중복 시 `PARSE_ERR_DUPLICATE`)
- L은 1개 이상, `MAX_LIGHTS`개까지 (초과 시 `PARSE_ERR_OVERFLOW`)
- sp, pl, cy, co는 1개 이상 필요
- 빈 줄과 `#` 주석 라인은 무시
- 오브젝트 색상 뒤 `checker:R,G,B` / `bump:path.xpm` 보너스 옵션 허용

### 파서 불변식 (runtime 신뢰)

렌더링 시작 전 파서가 보장하는 사항(중복 검사 불필요):

- ambient 1개, camera 1개
- `light_count >= 1`, `objects.count >= 1`
- 모든 축 벡터 정규화 및 비영벡터
- FOV ∈ [1, 179]
