# 개념: 퐁셰이딩 기초

> 이 문서는 누구를 위한 것인가
> - "왜 물체 한 면이 다른 면보다 밝은가?"가 궁금한 사람
> - ambient / diffuse / specular 세 항목이 어떻게 합쳐져 한 픽셀의 색이 되는지 직관을 잡고 싶은 사람

## 1. 셰이딩이란

**셰이딩(shading)** 은 "교차점에서 보이는 색을 계산하는 일"입니다. 재질의 원래 색, 광원의 밝기, 표면의 각도, 그림자 여부를 종합해 최종 RGB 값을 만듭니다.

miniRT는 고전적인 **Phong 반사 모델**을 씁니다. 세 항의 합으로 표현됩니다.

> 최종색 = (ambient 항) + (diffuse 항) + (specular 항)

각 항은 직관적으로 다음을 의미합니다.

| 항 | 의미 | 영향 요소 |
|----|------|-----------|
| Ambient | 씬 전체에 깔린 간접광 | 물체 본연의 색, ambient 비율 |
| Diffuse | 표면이 광원을 정면으로 볼수록 밝아짐 | 법선 ↔ 광원 방향 |
| Specular | 카메라가 반사각에 있을 때 반짝 | 법선 ↔ 반사 ↔ 시점 |

## 2. Ambient — 그림자 부분이 완전 검정이 아닌 이유

빛은 주변 물체에서 반사되어 여기저기 흩어지므로, 직접광이 닿지 않는 곳도 완전 검정은 아닙니다. 이것을 한 개의 상수로 "대충" 모사한 것이 ambient 입니다.

```
ambient_R = obj.color.R × (ambient.ratio × ambient.color.R)
```

miniRT는 `.rt` 파일에서 `A <ratio> <R,G,B>` 한 줄로 전체 씬에 하나만 지정합니다. 구현은 `src/lighting/shading/shading.c:124`.

## 3. Diffuse — 각도가 밝기를 결정

광원에서 온 빛이 표면에 **수직**으로 부딪히면 가장 밝고, **비스듬**할수록 어두워집니다. 이 "각도에 따른 밝기" 는 법선 $\hat{n}$ 과 광원 방향 $\hat{l}$ 의 내적:

> diffuse 강도 = max(0, $\hat{n} \cdot \hat{l}$)

```
    hat{l}
     ↘
      ↘      수직에 가까울수록 dot 값이 1에 가까워짐
       ↘      
        ●── hat{n}           : 밝음
       /
표면  ─────────

    hat{l}────────→         
      ●── hat{n}                : 어두움 (내적 ≈ 0)
       \
표면    \
```

miniRT 구현(`src/lighting/shading/shading.c:62`):

```c
light_dir = vec3_normalize(vec3_subtract(light->position, hit->point));
diffuse   = vec3_dot(hit->normal, light_dir);
if (diffuse < 0)
    diffuse = 0;            // 뒷면은 0으로 클램프
```

왜 `max(0, ...)` 인가요? 내적이 음수면 "광원이 표면 뒤편"이라는 뜻이라 빛이 안 닿아야 하기 때문입니다.

## 4. Specular — 반짝이는 하이라이트

매끈한 표면(플라스틱, 금속)은 특정 각도에서만 강한 반사광이 보입니다. Phong은 이것을 "반사 벡터와 시점 벡터의 내적의 거듭제곱"으로 모사합니다.

```
      광원            시점 (카메라)
        \              /
         \   반사벡터  /
          \  /       /
           \/       /
      ──────●──────── 표면
            ↑
           법선
```

1. 입사 방향의 반사 벡터 $\hat{r}$ 를 만든다 ($\hat{r} = 2(\hat{n}\cdot\hat{l})\hat{n} - \hat{l}$).
2. 시점 벡터 $\hat{v}$ 와 내적해서 $\cos\alpha$ 를 얻는다.
3. 큰 지수(여기선 32제곱)를 씌워 "중심 근처에서만 반짝"을 만든다.

miniRT 구현(`src/lighting/shading/shading.c:25`):

```c
reflect_dir = vec3_subtract(vec3_multiply(normal, 2.0 * dot_ln), light_dir);
spec = vec3_dot(reflect_dir, view_dir);
if (spec < 0.0) spec = 0.0;
spec = fast_pow32(spec);    // x^32 를 5번 제곱으로 빠르게
```

`fast_pow32()` 는 `pow(x, 32.0)` 대신 다섯 번의 제곱으로 계산해 속도를 끌어올립니다 (`src/lighting/shading/shading_utils.c:47`).

## 5. 그림자 섞기

접점에서 광원으로 광선(shadow ray)을 쏴 **막히면** diffuse + specular 를 제거합니다. miniRT는 부드러운 그림자를 위해 여러 개의 샘플을 쏘고 "가려진 비율"을 구해 0~1 값을 씁니다.

```c
// src/lighting/shading/shading.c:69
return ((diffuse + specular) * (1.0 - shadow_factor));
```

- `shadow_factor = 0.0`: 완전히 밝음
- `shadow_factor = 1.0`: 완전히 어두움 (ambient만 남음)

자세한 샘플링 방식은 [심화: 조명과 그림자 샘플링](심화-조명과-그림자-샘플링)을 참고.

## 6. 여러 광원 합치기

광원이 여러 개면 각 광원의 기여를 모두 더합니다.

```c
// src/lighting/shading/shading.c:88
while (i < scene->light_count)
{
    factor = calc_lighting_factor(scene, hit, light, view_dir);
    acc->r += factor * light->brightness * (light->color.r / 255.0);
    // g, b도 동일
    i++;
}
```

마지막에 ambient 항과 합친 뒤 [0, 255] 로 클램프 (`clamp_color`, `src/lighting/shading/shading_utils.c:23`).

## 7. 최종 합성 공식 정리

```
for each light L:
    diffuse_L  = max(0, n · l_L)
    specular_L = max(0, (r · v))^32
    shadow_L   = soft_shadow(point, L)    // 0..1
    factor_L   = (diffuse_L + 0.5*specular_L) * (1 - shadow_L)
    acc += factor_L * L.brightness * L.color

final = obj.color × (ambient.ratio × ambient.color + acc)
```

Phong이 아니라 Blinn-Phong, PBR 같은 더 정교한 모델도 있지만, 과제 범위에서는 Phong으로 충분합니다.
