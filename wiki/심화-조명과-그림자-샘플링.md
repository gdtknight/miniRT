# 심화: 조명과 그림자 샘플링

> 이 문서는 누구를 위한 것인가
> - "소프트 섀도우는 어떻게 가능해지는가?"를 실제 코드로 확인하고 싶은 사람
> - stratified sampling, offset LUT, any-hit 최적화의 근거를 알고 싶은 사람

## 1. apply_lighting — 셰이딩 진입점

한 픽셀의 hit에 대해 최종 색을 돌려주는 함수. `src/lighting/shading/shading.c:110`:

```c
if (hit->obj->has_checker)
    hit->color = checkerboard_color(hit->obj, hit);
if (hit->obj->bump_map)
    hit->normal = bump_perturb_normal(hit->obj, hit);
view_dir = normalize(camera.pos - hit.point);
accumulate_lights(scene, hit, view_dir, &acc);
result.r = obj.color.r × (ambient.ratio × ambient.color.r + acc.r) × 255;
clamp_color(&result);
```

텍스처 치환을 먼저 하고, 그 위에 광원 합산, 마지막에 ambient 와 합치는 순서.

## 2. accumulate_lights — 광원 루프

`shading.c:80`:

```c
while (i < scene->light_count) {
    factor = calc_lighting_factor(scene, hit, light, view_dir);
    acc->r += factor * light->brightness * (light->color.r / 255.0);
    // g, b 동일
    i++;
}
```

각 광원 기여를 독립적으로 계산해 누산. 광원이 많으면 선형으로 비용이 올라갑니다.

## 3. calc_lighting_factor — 한 광원의 기여

`shading.c:52`:

```c
light_dir     = normalize(light.position - hit.point);
diffuse       = max(0, dot(hit.normal, light_dir));
shadow_factor = calculate_shadow_factor(scene, query, light.position, &scene->shadow_config);
specular      = calculate_specular(light_dir, hit.normal, view_dir) * 0.5;
return ((diffuse + specular) * (1.0 - shadow_factor));
```

- Phong의 diffuse + specular 를 합산
- 그림자 계수 (0~1) 만큼 깎음
- specular 가중치는 0.5 (경험치)

## 4. calculate_specular — fast_pow32

`shading.c:25`:

```c
dot_ln      = dot(light_dir, normal);
reflect_dir = normal * 2*dot_ln - light_dir;
spec        = max(0, dot(reflect_dir, view_dir));
spec        = fast_pow32(spec);
```

`fast_pow32()` (`shading_utils.c:47`) 는 x를 다섯 번 제곱해 $x^{32}$ 를 만듭니다. `pow(x, 32.0)` 보다 수 배 빠릅니다.

## 5. calculate_shadow_factor — 샘플 집계

부드러운 그림자는 "광원을 작은 디스크처럼 취급하고, 여러 방향으로 광선을 쏴 가려진 비율"을 얻는 방식입니다. `src/lighting/shadow/shadow_calc.c:159`:

```c
local = *config;
if (scene->light_count > 1)
    local.samples = (config->samples + scene->light_count - 1)
                  / scene->light_count;   // 광원당 샘플 분배
shadow_count = calc_shadow_samples(scene, query, light_pos, &local);
return (shadow_count / (double)local.samples);
```

- 광원이 많을수록 광원당 샘플을 줄여 총비용을 일정 수준으로 유지.
- 반환값은 [0, 1]: 0=완전히 밝음, 1=완전히 그림자.

## 6. calc_shadow_samples — 샘플 루프

`shadow_calc.c:123`:

```c
while (i < config->samples) {
    if (sample_shadow_ray(&params, i))
        shadow_count += 1.0;
    i++;
}
```

각 샘플은 광원 위치를 조금씩 흔들어 가려진 샘플 수를 카운트합니다.

### 적응 바이어스

자기 표면이 자기 그림자를 만드는 "shadow acne" 를 막기 위해, 법선과 광원 방향 사잇각에 따라 바이어스를 키웁니다:

```c
// shadow_calc.c:28
angle_factor = 1.0 - |dot(normal, light_dir)|;
bias         = base_bias * (1.0 + angle_factor * 2.0);
```

정면(수직)일수록 작은 바이어스, 비스듬할수록 큰 바이어스.

## 7. sample_shadow_ray — 광원 위치 흔들기

`shadow_calc.c:85`:

```c
radius = config->softness * 2.0;
if (config->offset_lut)
    offset = vec3_multiply(config->offset_lut[index], radius);
else
    offset = generate_shadow_sample_offset(radius, index, config->samples);

light_dir = normalize(light_pos - query.point);

// 광원 방향 기준 tangent / bitangent 만들기
if (|light_dir.y| < 0.9)
    tang = normalize(cross(light_dir, (0, 1, 0)));
else
    tang = normalize(cross(light_dir, (1, 0, 0)));
bitang = cross(light_dir, tang);

jittered_pos = light_pos + tang * offset.x + bitang * offset.y;
return (shadow_is_occluded(scene, query, jittered_pos, bias));
```

디스크 좌표계의 offset을 (tang, bitang) 기저로 3D에 투영해서 광원 주변에 원반 형태로 샘플 위치를 흩뿌립니다.

## 8. offset LUT — 왜 미리 계산하는가

프레임마다 `sin/cos` 을 호출하면 비쌉니다. `init_shadow_config()` (`src/lighting/shadow/shadow_config.c:57`)는 프로그램 시작 시 샘플 개수만큼 stratified circular 오프셋을 미리 만들어 `offset_lut` 에 저장해 둡니다:

```c
grid_size = (int)sqrt(samples);
angle = 2π * (i % grid_size) / grid_size;
r     = (i / grid_size + 0.5) / grid_size;
offset[i] = (r*cos(angle), r*sin(angle), 0);
```

이렇게 만든 오프셋은 "중심 주변에 균등하게 흩어진 점들"이라 **stratified sampling** 에 해당합니다. 랜덤보다 분산이 작아 노이즈가 덜합니다.

기본값은 samples=16, softness=0.3 (`shadow_config.c:61`).

## 9. shadow_is_occluded — 교차 판정

`src/lighting/shadow/shadow_occlusion.c:112`:

```c
to_light = light_pos - query.point;
mag      = |to_light|;
init_shadow_ray(&ray, &query, to_light / mag, bias);
if (scene->bvh && objects.count > SHADOW_BVH_THRESHOLD)
{
    if (bvh_intersect_any(bvh, ray, mag, scene)) return 1;
    return (check_plane_shadow(scene, &ray, mag));
}
return (check_object_shadow(scene, &ray, &hit));
```

두 가지 경로:

- 객체 많음 + BVH 존재 → `bvh_intersect_any` + 평면 리스트
- 객체 적음 (≤ `SHADOW_BVH_THRESHOLD` = 5) → 모든 객체 스캔

`init_shadow_ray()` 는 원점을 법선 방향 + 광원 방향 양쪽으로 bias 만큼 밀어서 자기-교차를 방지 (`shadow_occlusion.c:88`).

## 10. 타임라인 요약

```
apply_lighting
 ├── (optional) checkerboard_color → hit.color 교체
 ├── (optional) bump_perturb_normal → hit.normal 교체
 └── for each light:
       ├── diffuse = max(0, n·l)
       ├── specular = fast_pow32(max(0, r·v))
       ├── for each shadow sample (16개 기본):
       │     └── shadow_is_occluded → bvh_any_hit or brute force
       ├── shadow_factor = 가려진 비율
       └── acc += (diff + 0.5*spec) * (1 - shadow) * brightness * color
     result = obj.color * (ambient + acc)
```
