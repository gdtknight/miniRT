# 심화: 텍스처와 범프맵

> 이 문서는 누구를 위한 것인가
> - `checker:` / `bump:` 옵션이 내부적으로 어떤 경로를 거치는지 보고 싶은 사람
> - UV 좌표, tangent/bitangent, 법선 섭동이라는 용어를 코드로 확인하고 싶은 사람

## 1. 큰 그림

셰이딩에서 두 개의 "표면 재질 꾸밈" 이 존재합니다.

1. **Checkerboard**: 접점의 UV 좌표를 기준으로 두 색을 번갈아 사용.
2. **Bump map**: 2D 높이맵 이미지를 sampling 해서 법선 방향을 살짝 흔들어 굴곡 있는 느낌을 냄(실제 기하는 그대로).

둘 다 `apply_lighting()` 도입부에서 한 번씩 실행되어 이후 diffuse/specular 계산의 입력을 교체합니다.

```c
// src/lighting/shading/shading.c:117
if (hit->obj && hit->obj->has_checker)
    hit->color = checkerboard_color(hit->obj, hit);
if (hit->obj && hit->obj->bump_map)
    hit->normal = bump_perturb_normal(hit->obj, hit);
```

## 2. Checkerboard — 도형별 UV

`src/lighting/texture/checkerboard.c:122` 의 `checkerboard_color()` 가 타입별로 분기.

### 평면

평면은 법선에 수직한 두 벡터(tangent, bitangent)로 접점을 투영:

```c
// checkerboard.c:26
tangent   = get_tangent(obj->data.plane.normal);
bitangent = vec3_cross(obj->data.plane.normal, tangent);
pattern   = floor(dot(hit.point, tangent)   / CHECKER_SCALE)
         + floor(dot(hit.point, bitangent) / CHECKER_SCALE);
if (pattern & 1) return (checker_color);
return (obj->color);
```

`CHECKER_SCALE = 2.0` (`includes/lighting/texture.h:19`). 두 투영 거리의 합이 홀수/짝수냐로 두 색 교대.

### 구

구는 경위도식 UV.

```c
u = 0.5 + atan2(local.z, local.x) / (2π);
v = 0.5 - asin(local.y) / π;
pattern = floor(u * 8) + floor(v * 8);
```

즉 가로 8칸, 세로 8칸. `asin` 의 클램프로 수치 오차에 의한 NaN 을 방지.

### 실린더/원뿔 body

축 기반 원통 좌표계. `atan2` 로 각도, 축 방향 투영으로 높이를 얻고 두 값을 체스판에 매핑 (`checker_body()`, `checkerboard.c:85`).

## 3. Bump Map — 로드

씬 파일에 `bump:textures/brick.xpm` 이 있으면 파서가 `obj->bump_path` 에 경로 문자열을 저장 (`parse_bonus_options.c:64`). 실제 이미지 로딩은 MLX 가 준비된 후 main 에서:

`src/main.c:149` → `load_all_bump_maps()` → `bump_map_load()`:

```c
// src/lighting/texture/bump_map_load.c:30
bmap->img  = mlx_xpm_file_to_image(mlx, filepath, &w, &h);
bmap->data = mlx_get_data_addr(bmap->img, &bpp, &size_line, &endian);
```

`t_bump_map` 구조체에 픽셀 데이터 포인터, bpp, size_line, 크기를 저장. 실패하면 에러를 출력하고 프로그램 종료.

종료 시 `cleanup_all_bump_maps()` 가 `mlx_destroy_image` + `free(bump_path)`.

## 4. Bump Map — 법선 섭동

`src/lighting/texture/bump_map_perturb.c:102` 의 `bump_perturb_normal()` 가 핵심:

```c
if (obj->bump_map->bpp != 32) return (hit->normal);  // 32비트 RGBA만 지원
get_surface_uv(obj, hit, uv);
compute_gradient(obj->bump_map, uv, grad);
tangent   = get_tangent(hit->normal);
bitangent = vec3_cross(hit->normal, tangent);
perturb   = tangent * grad[0] + bitangent * grad[1];
return (normalize(hit->normal + perturb));
```

### (a) UV 계산 — get_surface_uv

도형 타입별로 접점을 2D UV 로 펼칩니다 (`bump_map_perturb.c:44`).

- 구: checker_sphere 와 같은 경위도식.
- 실린더/원뿔: 축 기반.
- 기타: 접선 기저 투영.

### (b) 높이 샘플링 — sample_height

`bump_map_perturb.c:27`:

```c
offset = py * size_line + px * (bpp / 8);
return ((unsigned char)pixel[0] / 255.0);
```

XPM 에서 픽셀의 첫 바이트(endian에 따라 R 혹은 B)를 그레이스케일 height로 간주해 [0,1] 범위로 정규화.

### (c) 기울기 계산 — compute_gradient

`bump_map_perturb.c:75`:

```c
h     = sample_height(bmap, px, py);
grad[0] = sample_height(bmap, (px + 1) % W, py) - h;   // ∂h/∂u
grad[1] = sample_height(bmap, px, (py + 1) % H) - h;   // ∂h/∂v
```

인접 픽셀과의 차이를 "기울기"로 사용. 래핑(`% W`)으로 경계에서 이미지가 반복되게 함.

### (d) Tangent/Bitangent 구성

법선에 수직인 두 벡터를 만듭니다. `get_tangent()` 는 법선의 주요 축을 피해 임의의 보조 벡터로 외적해 tangent를 뽑는 헬퍼 (`src/lighting/texture/texture_utils.c`).

### (e) 섭동 벡터 합성

기울기가 큰 방향으로 법선이 살짝 기울도록:

```c
perturb = tangent * grad.u + bitangent * grad.v;
new_normal = normalize(normal + perturb);
```

## 5. 시각적 효과

```
원래 법선 (평평한 평면)
    ↑  ↑  ↑  ↑  ↑        →    조명 결과: 밝기 균일

bump 적용 후 법선
    ↑↗ ↑ ↖↑ ↑↘↑         →    조명 결과: 표면에 주름/요철
```

실제 지오메트리는 바뀌지 않으므로 실루엣은 매끄럽지만, diffuse·specular가 꺾인 법선을 쓰기 때문에 **조명만으로 굴곡을 만들어냅니다**. 낮은 비용으로 질감 풍부화.

## 6. 제약

- XPM 32bpp 만 지원 (`bump_perturb_normal:110`).
- RGB 를 단순 그레이스케일 하나로 읽음 (첫 바이트).
- 기울기를 central difference가 아니라 forward difference로 계산(간단/빠름).
- checkerboard 와 bump 는 독립적으로 조합 가능 (둘 다 켜면 체커색 위에 bump 주름).
