# 심화: 광선-객체 교차 수학

> 이 문서는 누구를 위한 것인가
> - 각 도형의 교차식이 어떻게 이차방정식 / 선형식으로 환원되는지 유도 보고 싶은 사람
> - `EPSILON`, `RAY_T_MIN` 같은 상수가 왜 필요한지 궁금한 사람

광선은 $P(t) = O + t \vec{d}$ ($t \ge 0$) 로 표현합니다. 교차식은 "표면 방정식 f(P) = 0 에 대입해 t를 푸는 문제"로 변합니다.

## 0. 공통 상수

`includes/common/ray.h:20`:

```c
# define EPSILON 0.0001        // 거의-0 판정
# define RAY_T_MIN 0.001       // t의 최소 허용값 (자기 그림자 방지)
# define COEFF_EPSILON 0.0001  // 계수 0 나누기 방지
```

- `RAY_T_MIN`: 광선 원점 바로 근처의 가짜 교차(부동소수점 잡음)를 걸러냄. 특히 그림자 광선이 자기 표면에서 시작할 때 중요.
- `EPSILON`: 이차방정식의 a가 거의 0이거나 법선이 거의 0인 degenerate 케이스를 걸러냄.

## 1. 구 (Sphere) — 이차방정식

조건: $|P - C|^2 = r^2$ 에 $P = O + t\vec{d}$ 대입.

$$|\vec{oc} + t\vec{d}|^2 = r^2$$
$$(\vec{d}\cdot\vec{d}) t^2 + 2(\vec{oc}\cdot\vec{d}) t + (\vec{oc}\cdot\vec{oc} - r^2) = 0$$

계수 $a, b, c$ 가 정의되면 판별식 $D = b^2 - 4ac$.

- $D < 0$: 교차 없음.
- $D \ge 0$: 두 근 $t_{1,2} = (-b \mp \sqrt{D}) / (2a)$. 작은 근부터 확인.

`src/spatial/intersect/intersect_object.c:28`:

```c
oc = vec3_subtract(ray->origin, s->center);
a = vec3_dot(ray->direction, ray->direction);
b = 2.0 * vec3_dot(oc, ray->direction);
c = vec3_dot(oc, oc) - s->radius_sq;
d = b * b - 4 * a * c;
if (d < 0 || a < EPSILON) return (0);
c = sqrt(d);
d = (-b - c) / (2.0 * a);
if (d < RAY_T_MIN)
    d = (-b + c) / (2.0 * a);   // 작은 근이 뒤로면 큰 근 시도
```

법선은 접점에서 중심을 빼고 정규화: $\hat{n} = (P - C) / r$.

## 2. 평면 (Plane) — 선형식

조건: $(P - P_0) \cdot \hat{n} = 0$. 선형이라 이차방정식 없음.

$$t = \frac{(P_0 - O) \cdot \hat{n}}{\vec{d} \cdot \hat{n}}$$

`src/spatial/intersect/intersect_object.c:69`:

```c
denom = vec3_dot(p->normal, ray->direction);
if (fabs(denom) < COEFF_EPSILON) return (0);   // 평면에 평행
p0l0 = vec3_subtract(p->point, ray->origin);
t    = vec3_dot(p0l0, p->normal) / denom;
if (t < RAY_T_MIN || t > hit->distance) return (0);
```

광선 방향이 법선과 내적이 양수면 "뒷면을 때린" 것이므로 법선을 뒤집어 셰이딩이 이상해지지 않게 합니다.

## 3. 실린더 (Cylinder) — 축 투영 + 이차

무한 실린더 조건: 축 방향 성분을 제거한 나머지 길이가 $r$.

$$|(P - C) - ((P - C)\cdot\hat{a}) \hat{a}|^2 = r^2$$

$P = O + t\vec{d}$ 를 대입하고 $\vec{oc} = O - C$, $d_a = \vec{d}\cdot\hat{a}$, $o_a = \vec{oc}\cdot\hat{a}$ 로 치환하면 이차방정식 계수:

- $a = \vec{d}\cdot\vec{d} - d_a^2$
- $b = 2(\vec{d}\cdot\vec{oc} - d_a o_a)$
- $c = \vec{oc}\cdot\vec{oc} - o_a^2 - r^2$

이게 `src/spatial/intersect/intersect_cylinder.c:36` 의 `calc_cyl_intersect()` 에 그대로 있습니다.

### 높이 범위 검사

무한 실린더로 얻은 $t$ 에서 축 방향 투영 $m = d_a t + o_a$ 가 $[-h/2, +h/2]$ 안에 있는지 확인합니다. 벗어나면 다른 근 $t_2$ 로 재시도.

### 법선

$\hat{n} = \text{normalize}(P - (C + m \hat{a}))$. 즉 "접점에서 축 위의 해당 지점까지의 수직 벡터".

### 캡

두 원형 뚜껑은 평면 교차 + 반경 내 판정의 조합입니다 (`intersect_cylinder.c:60` `intersect_cyl_cap()`). 각 캡의 법선은 축 벡터 (뒷면이면 뒤집음).

`intersect_cylinder()` 는 body + top cap + bottom cap 세 개를 순서대로 테스트해 가장 가까운 것을 유지합니다.

## 4. 원뿔 (Cone) — 2차식 + 높이 제한

정점에서 떨어질수록 반경이 커지는 관계를 이용합니다. miniRT는 정점이 `center + axis*half_height` 에 있고 밑면이 `center - axis*half_height` 에 있는 좌표계를 씁니다.

기울기 $k = r / h$, $k_2 = 1 + k^2$.

$$|(P - \text{apex})|^2 - k_2 ((P - \text{apex})\cdot\hat{a})^2 = 0$$

대입·정리하면 `src/spatial/intersect/intersect_cone_body.c:26` 의 계수:

- $a = \vec{d}\cdot\vec{d} - k_2 d_a^2$
- $b = 2(\vec{d}\cdot\vec{d_0} - k_2 d_a d_{0a})$
- $c = \vec{d_0}\cdot\vec{d_0} - k_2 d_{0a}^2$

여기서 $\vec{d_0}$ 는 원점에서 정점으로의 벡터. 법선은 접점에서 축 방향 성분을 빼 "위쪽을 향하는 cone 표면 normal" 로 교정합니다 (`set_cone_hit`, `intersect_cone_body.c:64`).

높이 범위: $m \in [-h, 0]$ (정점=0, 밑면=-h 인 좌표계). 범위 밖이면 다른 근 시도.

원뿔 밑면 cap은 별도 파일 `intersect_cone_cap.c` 에서 평면 + 반경으로 처리합니다.

## 5. 디스패치

`src/spatial/intersect/intersect_object.c:102`:

```c
if (obj->type == OBJ_SPHERE)
    result = intersect_sphere(...);
else if (obj->type == OBJ_PLANE)
    result = intersect_plane(...);
else if (obj->type == OBJ_CYLINDER)
    result = intersect_cylinder(...);
else if (obj->type == OBJ_CONE)
    result = intersect_cone(...);
if (result) hit->obj = obj;
```

셰이더가 material(checker, bump)를 참조하려면 `hit->obj` 가 필요하므로 마지막에 원본 객체 포인터를 박아 둡니다.

## 6. 왜 "가장 가까운" 것만 필요할까

광원 방향으로 가는 그림자 광선도 이 함수를 호출하지만, 실제로는 `hit.distance` 를 광원까지 거리로 초기화해 **그 거리 안쪽 교차만** 유효한 것으로 간주합니다. `bvh_intersect_any` 는 여기에 더해 "첫 교차면 즉시 리턴" 합니다 (`src/spatial/bvh/bvh_any_hit.c`).
