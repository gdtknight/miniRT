# 버전 히스토리

이 프로젝트의 주요 변경 사항을 기록합니다.

---

## [2.5.0] - 2026-04

### 리팩토링
- **기능 기반 7 패키지 재구성**: 기존 `src/parser/`, `src/window/`, `src/input/`, `src/display/`, `src/shading/`, `src/shadow/`, `src/texture/`, `src/bvh_vis/` 등을 `common`, `scene`, `spatial`, `render`, `lighting`, `interact`, `metrics` 7개 패키지로 재편성
- **헤더 구조 정리**: `includes/`가 `src/` 구조를 그대로 반영. `#include "package/header.h"` 형식 강제. 내부 헤더(`_internal.h`)와 타입 전용 헤더 분리로 순환 의존 제거
- **Spatial 통합**: BVH/AABB/Intersect/BVH 디버그를 `src/spatial/{bvh,aabb,intersect,debug}/`로 통합. `bvh_vis_*` → `bvhd_*` 접두사 변경
- **Display 모듈 해체**: MLX 창/이미지 관리는 `src/render/window_*.c` + `src/render/put_pixel.c`로, 이벤트 콜백은 `src/interact/event_dispatch.c`로 이동
- **타입 안전성**: BVH 함수가 `void *` 대신 `t_scene *`를 받도록 변경. 통합 hit record `t_hit`만 사용 (`t_hit_record` 제거)
- **Shadow config 소유권**: `t_shadow_config`를 `t_scene`에 임베드해 `scene.h`가 `lighting/`에 의존하지 않도록 정리

### 수정
- Camera pitch 360° 회전 복원

### 문서
- wiki/ 전체 갱신: 7 패키지 구조, 새 경로, `bvhd_*` 접두사, `bvh_any_hit` 함수명

## [2.4.0] - 2026-03

### 리팩토링
- **Input 모듈 분리**: `input_dispatch.c`, `input_camera.c`, `input_objects.c`, `input_resize.c`, `input_rotate.c`를 `src/window/`에서 `src/input/`으로 이동
- **Metrics 모듈 분리**: `metrics_*.c`를 `src/render/`에서 `src/metrics/`로 이동
- **파일 이름 변경**: `trace.c` -> `render_trace.c`, `camera.c` -> `render_camera.c`, `intersect_cyl_new.c` -> `intersect_cylinder.c`, `vector.c` -> `vec3.c`, `bounds.c` -> `aabb_bounds.c`
- **Dead code 제거**: pixel_timing 모듈, 미사용 `handle_key_release`, dead HUD 파일 제거
- **Main 리팩토링**: `init_scene` 및 `load_bump_maps` 헬퍼 함수 추출

### 수정
- **Linux 정리**: 올바른 X11 정리를 위한 `mlx_destroy_display` 호출 추가
- **Shadow 샘플링**: 광원별 샘플 조정 시 올림 나눗셈 수정
- **안전 가드**: utils/bvh_vis NaN 가드, HUD 버퍼 오버플로 수정, cylinder/cone 교차 시 zero-normal 안전 처리

### 문서
- 파일 이름 변경 및 모듈 분리에 따른 docs/ 모듈 페이지 전체 갱신
- wiki/ 페이지 전체 갱신: 키 바인딩, 디바운스 FSM, 해상도, 다중 광원, 원뿔, 보너스 옵션

## [2.3.0] - 2026-02

### 추가
- **오브젝트 리사이즈**: Y/U 키로 반지름, N/M 키로 원기둥 높이 조절
- **오브젝트 회전**: I/J (X축), O/K (Y축), P/L (Z축) Rodrigues 회전
- **LQ 프리뷰 속도 제한(throttle)**: 디바운스 중 50ms 간격 low quality 프리뷰

### 변경
- **디바운스 FSM 재설계**: 4-상태 머신 IDLE -> ACTIVE (150ms) -> FINAL -> COOLDOWN (350ms)으로 단순화. PREVIEW 상태 제거
- **키맵 재구성**: 광원 이동 키를 `[`/`]`/`;`/`'`/`,`/`.`으로 변경, 오브젝트 선택을 TAB으로 통일, HUD 페이지를 Up/Down으로 변경
- **렌더 플래그**: `RENDER_SHOW_INFO`, `RENDER_SHIFT_HELD` 제거

### 제거
- **Dead Code 정리**: I 키 정보 토글 핸들러, shift 키 핸들링, 미사용 키 정의 (Insert, Home, PgUp, Delete, End, PgDn, Left, Right) 제거

## [2.2.0] - 2026-02

### 추가
- **Plane BVH 분리**: Plane을 BVH 트리에서 분리하여 bounded 오브젝트만으로 트리 구축
- **Shadow BVH Any-Hit**: Shadow ray에 early-exit BVH 순회 적용
- **Shadow Offset LUT**: cos/sin/sqrt 사전 계산으로 shadow sampling 가속
- **수학 연산 최적화**: `fast_pow32`, sphere sqrt 캐싱, shadow magnitude 통합
- **inv_dir 사전 계산**: 레이 생성 시 `1/direction` 사전 계산 (AABB 교차 최적화)
- **카메라 Basis 캐싱**: 카메라 basis 벡터(right, up) 프레임당 1회 계산 후 캐시
- **BVH Child Ordering**: 레이 방향 기준 가까운 자식 우선 순회
- **시작 시 메트릭 출력**: 시작 시 성능 메트릭 자동 출력

### 변경
- **Shadow BVH Threshold**: 20 -> 5로 하향 (더 작은 씬에서도 BVH 활용)

### 수정
- **Shadow offset LUT**: 샘플 수 변경 시 LUT 재생성
- **Parser FOV**: FOV 범위를 exclusive (0, 180)으로 수정
- **BVH malloc guard**: `scene_build_bvh`에서 malloc 실패 시 안전 처리
- **plane_refs leak**: BVH 재구축 시 plane_refs 메모리 누수 수정
- **Parser line buffer**: `finalize_line`에서 null-terminate 보장
- **Parser failure cleanup**: parse 실패 시 미처리 라인 메모리 해제

### 성능
- S4 (혼합 18obj): 27.2s -> 6.1s (77.7% 개선)
- S3 (50 spheres): 3.4s -> 1.4s (57.4% 개선)
- Shadow tests (S4): 369M -> 83.7M (-77.4%)
- BVH skip rate (S4): 32.9% -> 82.0%

## [2.1.0] - 2026-01-15

### 추가
- **BVH 가속**: 기본 활성화, 복잡한 씬에서 2~10배 렌더링 가속
- **디바운스 렌더링**: 150ms 디바운스 타이머 기반 렌더링 최적화
- **BVH 트리 시각화**: `--bvh-vis` 플래그로 BVH 트리 구조 콘솔 출력
- **통합 오브젝트 식별자**: 일관된 오브젝트 식별자 체계 (sp-1, pl-1, cy-1, co-1)
- `RENDER_RENDERING` 비트 플래그로 정확한 렌더 진행 추적

### 변경
- 100% Norminette 준수 달성
- 헤더 인클루드 구조 개선

### 수정
- BVH 활성화 시 검정 화면 문제
- 렌더 취소 로직 (실제 렌더링 중일 때만 취소)

### 성능
- BVH: 복잡한 씬에서 2~10배 가속
- 디바운스: 입력 중 불필요 렌더 90%+ 감소
