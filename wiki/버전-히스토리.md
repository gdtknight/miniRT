## [2.4.0] - 2026-03

### 주요 변경사항

- **모듈 리팩토링**: `src/input/` 모듈 분리, `src/metrics/` 모듈 분리
- **파일 리네이밍**: `render_trace.c`, `render_camera.c`, `intersect_cylinder.c`, `vec3.c`, `aabb_bounds.c`
- **Dead code 제거**: pixel_timing 모듈 삭제, `handle_key_release` 제거
- **버그 수정**: Linux mlx 클린업, shadow 샘플 보정, NaN 가드, 버퍼 오버플로 수정
- **문서 전면 업데이트**: docs/ 및 wiki/ 전체를 현재 구현에 맞게 갱신

---

## [2.3.0] - 2026-02

### 주요 변경사항

- **Object Resize**: Y/U 키로 반지름, N/M 키로 높이 조절
- **Object Rotation**: I/J, O/K, P/L Rodrigues 회전
- **Debounce FSM 재설계**: IDLE -> ACTIVE -> FINAL -> COOLDOWN (PREVIEW 제거)
- **Keymap 변경**: 광원 []/;'/,., 오브젝트 선택 TAB, HUD 페이지 Up/Down
- **Dead code 제거**: 미사용 핸들러 및 코드 정리
- **Input 모듈 분리**: `src/input/`으로 입력 처리 코드 이동
- **Render 모듈 정리**: render_loop.c, render_flags_set.c를 `src/render/`로 이동

---

## [2.2.0] - 2026-02

### 주요 변경사항

- **Plane BVH 분리**: Plane을 BVH 트리에서 제외하여 트리 품질 개선
- **Shadow BVH Any-Hit**: 그림자 광선에 early exit 최적화 적용
- **Shadow Offset LUT**: 소프트 섀도우 오프셋 사전 계산
- **fast_pow32**: 5번의 곱셈으로 specular 계산 최적화
- **inv_dir 사전 계산**: 광선 구조체에 역방향 사전 저장
- **Camera basis 캐싱**: dirty flag로 불필요한 재계산 방지
- **BVH child ordering**: 광선 방향 기반 자식 노드 순서 최적화

### 성능 개선

- S4 성능: 27.2s -> 6.1s (77.7% 개선)

## [2.1.0] - 2026-01-15

### 주요 변경사항

- **BVH 가속 구조 (Spec 017)**: 복잡한 장면에서 2-10배 렌더링 속도 향상
  - 기본 활성화로 별도 설정 불필요
  - O(log n) 트리 순회로 교차 검사 최적화
  - 50개 이상 객체 장면에서 최대 성능 발휘

- **디바운싱 렌더링 (Spec 018)**: 90% 이상 불필요한 렌더링 제거
  - 150ms 디바운스 타이머로 입력 버퍼링 제거
  - 4-상태 기계 (IDLE → ACTIVE → PREVIEW → FINAL)
  - 부드러운 인터랙션과 즉각적인 시각 피드백 제공

- **프리뷰 모드**: 인터랙션 중 즉각적인 시각적 피드백
  - 저품질 프리뷰 렌더링으로 즉시 반응
  - 자동으로 고품질 최종 렌더링으로 전환

- **100% Norminette 준수 (Spec 016)**: 모든 코드가 42 School 코딩 규칙 준수
  - 전체 코드베이스 norminette 통과
  - 일관된 코드 스타일과 품질

- **통합 객체 식별자 (Spec 015)**: 일관된 객체 관리 시스템

- **BVH 트리 시각화 (Spec 014)**: `--bvh-vis` 플래그로 디버그 시각화 지원

### 성능 개선

- BVH 가속: 복잡한 장면(50+ 객체)에서 2-10배 속도 향상
- 디바운싱: 인터랙션 중 불필요한 렌더링 90% 이상 감소
- 메모리 누수 제로, 새 코드에서 힙 할당 제로

### 버그 수정

- BVH 활성화 시 검은 화면 문제 해결
- 렌더링 중일 때만 취소하도록 로직 개선
- 사양 번호 일관성 수정

### 문서화

- 18개 기능 사양 문서 작성
- 포괄적인 Doxygen 스타일 주석
- API 계약 및 데이터 모델 완성

### 세부사항
