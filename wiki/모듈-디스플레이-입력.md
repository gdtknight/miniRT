# 모듈: 디스플레이 / 입력 (interact 패키지)

MiniLibX 창/이미지 관리는 `render` 패키지, 이벤트/키 입력/HUD/키가이드는 `interact` 패키지가 담당합니다. 리팩토링 이후 옛 `src/display/`와 `src/input/`은 각각 `src/render/window_*.c` + `src/interact/event_dispatch.c`, `src/interact/input/`으로 이동되었습니다.

---

## 소스 파일

### 창 / 픽셀 (`src/render/`)

| 파일 | 역할 |
|------|------|
| `window_init.c` | `mlx_context_init` — `mlx_init`, `mlx_new_window`, `mlx_new_image`, `mlx_get_data_addr` |
| `window_destroy.c` | MLX 이미지/창 정리 (Linux 시 `mlx_destroy_display` 포함) |
| `put_pixel.c` | `put_pixel_to_buffer` — 이미지 버퍼 픽셀 쓰기 / 포맷 변환 |

### 이벤트 디스패치 (`src/interact/`)

| 파일 | 역할 |
|------|------|
| `event_dispatch.c` | `handle_key`, `close_window`, `handle_expose` — MLX 이벤트 콜백 |

### 입력 (`src/interact/input/`)

| 파일 | 역할 |
|------|------|
| `input_dispatch.c` | 키 입력 분기 (`handle_hud_keys`, `handle_camera_keys`, `handle_transform_keys`) |
| `input_camera.c` | 카메라 이동/pitch/yaw/리셋 |
| `input_objects.c` | 오브젝트 및 광원 이동 |
| `input_resize.c` | 오브젝트 리사이즈 (Y/U 반지름, N/M 높이) |
| `input_rotate.c` | 오브젝트 회전 (I/J X, O/K Y, P/L Z) |
| `input_key_binds.c` | 키코드-핸들러 바인딩 테이블 |
| `input_key_binds_extra.c` | 추가 키 바인딩 |

### HUD (`src/interact/hud/`)

| 파일 | 역할 |
|------|------|
| `hud_init.c` | HUD 초기화, 총 페이지 수 계산 |
| `hud_render.c` | HUD 렌더링 진입점 |
| `hud_scene.c` | 씬 정보 (카메라/조명/오브젝트 개요) |
| `hud_objects.c` | 오브젝트 목록 페이지네이션 |
| `hud_obj_render.c` | 개별 오브젝트 정보 렌더링 |
| `hud_performance.c` | 성능 메트릭 (FPS, 렌더 시간, BVH 상태) |
| `hud_text.c` | HUD dirty 마킹, vec3 포맷 |
| `hud_format.c` | 숫자/벡터 포맷 |
| `hud_format_helpers.c` | 포맷 헬퍼 |
| `hud_toggle.c` | HUD 토글 (H 키) |
| `hud_navigation.c` | 페이지 네비게이션 |

### Keyguide (`src/interact/keyguide/`)

| 파일 | 역할 |
|------|------|
| `keyguide_init.c` | 키가이드 초기화 |
| `keyguide_render.c` | 오버레이 렌더링 |
| `keyguide_render_extra.c` | 추가 키 정보 렌더링 |

공개 헤더: `includes/interact/event.h`, `interact/input.h`, `interact/hud.h`, `interact/keyguide.h`, `interact/ui_types.h`, `interact/key_binds.h`.

## MiniLibX 초기화

```
render_create(scene)
 ├── malloc(t_render)
 ├── mlx_context_init()
 │    ├── mlx_init()
 │    ├── mlx_new_window(WINDOW_WIDTH=1440, WINDOW_HEIGHT=900, "miniRT")
 │    ├── mlx_new_image()
 │    └── mlx_get_data_addr()
 ├── debounce_init()
 ├── hud_init() / keyguide_init()
 └── 이벤트 훅 등록
      ├── mlx_hook(close_window)
      ├── mlx_hook(handle_key)
      ├── mlx_hook(handle_expose)
      └── mlx_loop_hook(render_loop)
```

해상도: 1440 × 900 (고정, `includes/render/window.h`).

## 이벤트 처리

```
handle_key(keycode, render)
 ├── ESC → close_window()
 ├── H/TAB/Up/Down/= → handle_hud_keys()
 ├── W/X/A/D/Q/Z/E/C/S/1/3 → handle_camera_keys()
 └── R/T/F/G/V/B/[/]/;/'/,/./Y/U/N/M/I/J/O/K/P/L → handle_transform_keys()
      ├── R/T/F/G/V/B → handle_object_move()
      ├── [/]/;/'/,/. → handle_light_move()
      ├── Y/U/N/M → handle_object_resize()
      └── I/J/O/K/P/L → handle_object_rotate()
```

키 누름 시 디바운스 FSM이 LQ 프리뷰(50ms 스로틀)를 트리거하고, 150ms 무입력 시 Full Quality 렌더를 수행합니다.

## HUD 렌더링

```
hud_render(render)
 ├── [hidden] return
 ├── hud_render_content()
 │    ├── hud_render_camera()        // 카메라 위치/방향/FOV
 │    ├── hud_render_ambient()       // 환경광
 │    ├── hud_render_light()         // 선택 광원 위치/밝기/색상
 │    ├── hud_render_objects()       // 오브젝트 목록 (현재 페이지)
 │    └── hud_render_performance()   // 성능 메트릭
 └── hud.dirty = 0
```

오브젝트 수가 `HUD_OBJECTS_PER_PAGE` (8)를 초과하면 페이지 단위로 분할되며 Up/Down으로 이동합니다.

## 리소스 정리

```
close_window(render)
 ├── cleanup_all_bump_maps()
 ├── render_destroy(render)
 │    ├── mlx_context_destroy()    // Linux: mlx_destroy_display 포함
 │    └── free(render)
 ├── scene_destroy(scene)
 │    ├── object_list_destroy()
 │    ├── bvh_destroy()
 │    ├── free_shadow_offset_lut()
 │    └── free(scene)
 └── exit(0)
```

## 플랫폼 차이

| 항목 | macOS | Linux |
|------|-------|-------|
| 키 코드 | `includes/interact/input.h` `__APPLE__` 섹션 | `__linux__` 섹션 |
| MLX 정리 | `mlx_destroy_image` + `mlx_destroy_window` | 추가로 `mlx_destroy_display()` |
| 링크 플래그 | OpenGL + AppKit | X11 + Xext |
